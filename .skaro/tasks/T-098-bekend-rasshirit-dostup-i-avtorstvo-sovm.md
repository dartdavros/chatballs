## Цель

Реализовать права и авторство участников, атомарное управление составом, защищённый журнал и уведомления о подключении.

## Критерии приёмки

- [x] Активное участие даёт согласованные права чтения и ответа без перехвата ответственного.
- [x] Отзыв участия прекращает основанный на нём HTTP/realtime доступ, сохраняя независимые права.
- [x] Автор каждого сообщения остаётся конкретным сотрудником; чужая организация и блокировка запрещают операцию.
- [x] Добавление и удаление проверяют права и атомарный лимит при конкуренции; повторы идемпотентны.
- [x] Состав и журнал защищены; уведомления realtime доставляются по доступу после операции.
- [x] Клиент получает только согласованное уведомление о специалисте, без внутренней причины.

## Заметки

Основание границ задачи: Доступ участника и управление составом не должны расходиться между отдельными ветками. Серверный сценарий полезен независимо от UI и завершает API совместной работы.
