## Цель

Текст согласия хранит безопасный HTML по белому списку SPEC-0020 R-14–R-15; версия повышается по очищенному тексту. В W2 под полем — подсказка о тегах (R-17).

## Критерии приёмки

- [x] Добавлена зависимость `nh3`; при сохранении подключения `consentText` очищается по белому списку SPEC-0020 R-14, у ссылок проставляются `target="_blank"` и `rel="noopener noreferrer nofollow"`, `javascript:` и прочие схемы удаляются.
- [x] Публичная конфигурация виджета отдаёт очищенный текст и для записей, сохранённых до очистки.
- [x] Версия согласия меняется только при изменении очищенного текста; существующий тест `test_consent_version_is_owned_by_server_and_changes_only_with_text` проходит, добавлены тесты на `script`, `on*`, `javascript:` и разрешённые теги.
- [x] Под полем «Текст согласия» в разделе «Форма перед чатом» — подсказка ровно по кадру W2 («Можно использовать ссылки, жирный и курсив, подчёркнутый, переносы, абзацы и списки (HTML). Остальная разметка покажется простым текстом.») из словарей ru и en.

## Заметки

Макет: кадр W2 в `design/baseline/Веб-чат · поля и оформление/`. Сервер: webchat/pre_chat.py (версия), webchat/configuration.py (публичная выдача), integrations/serializers.py; фронт — internal-ui/src/features/integrations/pre-chat/PreChatText.tsx. Тесты бэкенда — из контейнера backend-admin, только затронутые модули, `--reuse-db`.

## Итог

Текст согласия теперь очищается на сервере по белому списку SPEC-0020 R-14 (nh3): при сохранении подключения, при выдаче публичной конфигурации и в ответе настроек; версия согласия сравнивается по очищенному тексту. В разделе «Форма перед чатом» под полем «Текст согласия» добавлена подсказка о разрешённой разметке из словарей ru и en, высота поля приведена к кадру W2 (112px). Проверено тестами и сквозной проверкой в окружении задачи skaro-chatballs-t-026 (frontend http://localhost:20004, api http://localhost:20002).
