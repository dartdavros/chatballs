## Цель

Исправить переполнение интерфейса после расширения каталога Chatballs в двух показанных владельцем местах. В контакте использовать существующий компактный вход ручного запуска, а редактор прав агента перенести в штатную модалку с поиском и категориями.

## Критерии приёмки

- [x] В блоке контакта больше не разворачивается весь каталог ссылок на управление сценариями, агентами и прочими сущностями. Используется уже существующий ManualActionMenu/штатный компактный вход запуска; карточка и её остальные разделы не растягиваются каталогом.
- [x] Из контакта сохраняется доступ к прежним разрешённым ручным операциям/сценариям и их форме запуска; ContactEntityLinks, сведения о контакте, текущие проверки полномочий/контекста и недоступные действия сохранены. Исправление не скрывает функциональность без альтернативного штатного входа и не выдаёт новые права.
- [x] Полный список режимов «Действия и сценарии» удалён из карточки агента; из существующего блока открывается штатный antd Modal. Используются существующие AgentKnowledgeDialog, SearchInput, Button, Segmented и стили. Отдельный дизайн-baseline не создаётся по прямому указанию владельца «Дизайн тут не нужен».
- [x] В модалке права сгруппированы по предметным разделам Chatballs, сценарии выделены отдельно, внешние операции разделены по подключениям. Каждая строка имеет ровно одну категорию; весь каталог сохраняется. Категории определяются устойчивыми идентификаторами/метаданными, без разбора переведённого названия и второго ручного перечня операций.
- [x] Поиск без учёта регистра работает по названию действия и категории/подключению, оставляет только подходящие строки и непустые группы; очистка возвращает каталог. Пустой каталог, отсутствие совпадений, загрузка и ошибка используют существующие состояния.
- [x] Смена поиска и группы не теряет выбранные режимы. Явное сохранение использует существующие useAgentActions/saveActions и включает изменённые строки вне фильтра; сохраняются revision/conflict handling, блокировка повторного сохранения, предупреждения self и данные подтверждения ask.
- [x] Отмена/крестик/Escape не отправляют изменение прав; несохранённые изменения обрабатываются штатным паттерном. Сохранённые режимы корректны при повторном открытии. Перенос не меняет off по умолчанию, права делегата и runtime исполнителя.
- [x] Длинный фактический каталог прокручивается внутри модалки; заголовок, поиск и действия доступны. Обе карточки проверены в штатном браузере на 1024/1440 и в обеих темах; для блока контакта также проверен существующий мобильный чат. Нет горизонтального переполнения и нарушения геометрии.
- [x] Выполнены сборка internal-ui и необходимые целевые тесты поиска/категорий/сохранения скрытых правок и затронутого ручного запуска. Модель фильтрации/группировки отделена от строк/модалки; backend меняется только при необходимости метаданных, без изменения бизнес-политики.
