## Цель

Показать сохранённые оформленные ответы в виджете, ленте сотрудника и проверочном чате одним защищённым компонентом. Воспроизвести W1–W4/F1–F3 и фактически отправленный текст для текстовых транспортов.

## Критерии приёмки

- [x] Общий renderer предпросмотра переиспользован в виджете, ленте и TestChatFeed; исполняемого кода/внешних загрузок нет, CSS не меняет соседние сообщения/оболочку. Отдельный небезопасный dangerouslySetInnerHTML/renderer в приложении не вводится.
- [x] W1/W2: короткий и длинный заказ из 7 позиций показываются внутри пузыря, названия переносятся, суммы сохраняют структуру; горизонтального скролла нет. W3: срок без eta скрыт. W4: телефон 360 и ширины карточки 300/340 проверены.
- [x] F1: автор, время и прочтение остаются; название шаблона взято из метаданных отправленного снимка, действие «Текстовая версия» раскрывает сохранённый text по дополнению UI. F2: текстовый транспорт показывает отправленный текст, не HTML-карточку.
- [x] F3: изменение/удаление навыка или шаблона не меняет содержимое истории после обновления страницы и повторной загрузки. Пояснение об изменённом шаблоне показывается только при известной более новой ревизии, без пересборки; удаление исходного объекта не ломает карточку.
- [x] HTTP/WebSocket-обновления не дублируют карточки, загрузка истории сохраняет порядок и прокрутку; позднего ответа после перехвата не возникает. Старые текст/вложения/голосовые и HTML входящей почты проходят непосредственно затронутые регрессии.
- [x] Проверочный чат показывает тот же безопасный снимок в существующей оболочке, не добавляет придуманных плашек внутренних операций. Отказ и обычный ответ отображаются как раньше.
- [x] Публичный UI использует только разрешённый контракт сообщения, не обращается за инструкциями/схемами/текущим шаблоном; повреждённое/неподдерживаемое представление безопасно показывает сохранённый текст без сырого HTML и технических токенов.
- [x] В задачу включены RU/EN i18n, применимая сборка и только относящиеся к изменениям тесты, browser-проверка на штатном backend в обеих темах и проверка SRP/NO GOD FILES. Показанные кадры сохраняются, недостающие состояния — только по docs/agent-skills-ui-agreement.md. Никаких seed, сбросов учётных данных, fake backend или полного прогона.

## Заметки

Источники: baseline/agent-skills/Оформленные сообщения.dc.html W1–W4/F1–F3; docs/agent-skills-ui-agreement.md. Все потребители снимка объединены, чтобы подтвердить один renderer и одинаковое содержимое клиента/сотрудника. Зависимость от редактора осознанная: тот поставляет общий renderer в packages/ui; второй вариант элемента запрещён. Это не основание менять всю существующую оболочку чата или почтовый renderer.

## Итог

Сохранённые оформленные ответы подключены к виджету, ленте сотрудника и TestChatFeed через общий защищённый PreparedMessage. Добавлены текстовая версия, подсказка о более новой ревизии без пересборки истории, безопасный fallback и RU/EN; выполнены целевые проверки и browser-сверка на штатном backend, кадры и ограничения сохранены в docs/verification/T-163.
