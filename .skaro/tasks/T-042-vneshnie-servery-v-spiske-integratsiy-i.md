## Цель

Внешние серверы видны в общей таблице интеграций, добавляются через меню вида, у сервера есть своя страница с шапкой и субменю (R-7, R-8).

## Критерии приёмки

- [x] Таблица интеграций: строка внешнего сервера и колонка «Агент · инструменты» — по кадру X1; «Добавить» открывает меню: точка входа диалогов, MCP-сервер, HTTP-запрос.
- [x] Страница сервера: шапка, субменю, контент — как страница веб-подключения, с переиспользованием её каркаса; состояния загрузки, «не удалось загрузить», «сервер не найден» — по X9.
- [x] Блок о подменяемых данных со ссылкой на справку — по макету.
- [x] Тексты в словарях ru и en, `tsc` проходит, компоненты не больше ~200 строк.
