## Цель

Реализовать настройки и модель запроса оценки, безопасный публичный приём, планирование и доставку запроса, а также защищённый источник результатов для карточки и отчётов.

## Критерии приёмки

- [x] Настройки содержат включение, шкалу, текст и задержку; исходно запросы выключены.
- [x] Один запрос на событие завершения хранит снимок шкалы и фактически отвечавших сотрудников.
- [x] Уникальность и tenant-связи не допускают дубль, чужое обращение или переинтерпретацию старой оценки.
- [x] Ограниченный credential хранится хешем, имеет срок и не раскрывает историю или контакт.
- [x] Принимаются только допустимое значение и ограниченный комментарий; повтор идемпотентен, замена получает конфликт.
- [x] Защита частоты и прямых IDs не даёт ответить за чужой запрос.
- [x] Завершение планирует запрос по задержке; выключение и удаление обращения отменяют ожидающую отправку.
- [x] Повтор события и воркера не порождает второй логический запрос клиенту.
- [x] Согласованные транспортные адаптеры доставляют ограниченную форму либо принятую нативную оценку, без выдуманных текстов.
- [x] Результаты связаны с обращением и фактически отвечавшими сотрудниками, одна оценка не умножается в итогах.
- [x] OWNER/ADMIN и супервизор видят разрешённую область; доступ оператора соответствует отдельному решению.
- [x] Разные шкалы сохраняют снимки и возвращаются раздельно, не усредняются без правила.
