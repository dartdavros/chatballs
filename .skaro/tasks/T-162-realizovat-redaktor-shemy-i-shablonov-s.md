## Цель

Дать администратору законченный редактор HTML/CSS/текста и типизированных входных полей с серверным предпросмотром по T1–T4. Сохранять весь локальный набор навыка атомарно и воспроизводить те же безопасные карточки.

## Критерии приёмки

- [x] Редактор повторяет три колонки T1, вкладки HTML/CSS/Текст, режимы Виджет/Текст и ширины 340/300; код редактируется без исполнения, сохраняется универсальный шаблон, а не особый компонент заказа.
- [x] Создание, изменение/удаление полей, вложенные объекты и списки используют точные Modal/контролы docs/agent-skills-ui-agreement.md. Нет неизвестных родительских узлов/циклов; изменение схемы корректно запускает общую валидацию ссылок и типов.
- [x] Редактируемые JSON-примеры и готовые короткий/длинный/со сроком/без срока вызывают серверный предпросмотр; устаревшие ответы игнорируются. Предпросмотр и текст используют общий защищённый renderer, сохраняемый результат соответствует ему.
- [x] По T2 ошибки локализованы в строке/поле/вкладке и сводке; ошибки конфигурации блокируют сохранение, ошибка временного примера блокирует соответствующий предпросмотр по R-14. Пример с qty='два', отсутствующим total, неизвестным discount и незакрытым each диагностируется.
- [x] Отсутствие eta по T3 скрывает строку, не подставляет тире/пустой блок. Семь длинных позиций, форматирование чисел и обе ширины совпадают с baseline.
- [x] Кнопки сохранения навыка/шаблона и T4 используют один локальный набор/ревизию и атомарное применение; при затрагивании других частей показано согласованное пояснение. Невалидный родитель, сбой и конфликт не теряют ввод и не вызывают уход.
- [x] Выбор основы и готовые исходники остаются редактируемыми; пользовательские инструкции/тексты не переводятся автоматически после установки. Недостающие состояния не изобретаются и не превращаются в визуальный конструктор.
- [x] В задачу включены RU/EN i18n, применимая сборка и только относящиеся к изменениям тесты, browser-проверка на штатном backend в обеих темах и проверка SRP/NO GOD FILES. Показанные кадры сохраняются, недостающие состояния — только по docs/agent-skills-ui-agreement.md. Никаких seed, сбросов учётных данных, fake backend или полного прогона.

## Заметки

Источники: baseline/agent-skills Навыки агентов T1–T4 и обязательное дополнение UI. Схема, код, пример и preview объединены, поскольку это один цикл проверки/сохранения шаблона. Отделено от библиотеки из-за самостоятельного сложного workflow редактирования кода; от ленты сообщений — для независимой работы после готовности сервера. Общий renderer допустимо реализовать в packages/ui в этой задаче, чтобы последующая UI-задача переиспользовала его; не создавать два стандарта.
