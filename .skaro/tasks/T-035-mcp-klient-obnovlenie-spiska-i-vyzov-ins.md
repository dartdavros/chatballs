## Цель

Сервер получает и хранит снимок инструментов MCP, вызывает инструмент и проверяет соединение (R-2, R-5).

## Критерии приёмки

- [x] Streamable HTTP: `initialize`, `tools/list` и `tools/call` через клиент из задачи о защищённом исходящем клиенте.
- [x] «Обновить список инструментов» сохраняет снимок (имя, описание, `inputSchema`, `readOnlyHint`) и время; при ошибке прежний снимок сохраняется.
- [x] Проверка соединения выставляет статус; ошибки различаются по состояниям X5 (недоступен, неверная авторизация, адрес запрещён, без инструментов) и не содержат тела чужого ответа.
- [x] Тесты с поддельным MCP-сервером: снимок, вызов, ошибка авторизации, таймаут.

## Итог

Добавлен MCP-клиент по Streamable HTTP (initialize, tools/list, tools/call) поверх защищённого исходящего клиента из T-033. «Обновить список инструментов» (POST /integrations/{id}/tools/refresh/) сохраняет снимок и время в интеграции, при ошибке прежний снимок остаётся; проверка соединения выставляет статус и код состояния по кадру X5. Только бэкенд: интерфейса в этой задаче нет.
