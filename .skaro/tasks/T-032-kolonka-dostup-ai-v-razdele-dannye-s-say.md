## Цель

Тумблер «Видит AI» заменяется выбором «Не видит / Под маской / Видит значение» ровно по кадру W1 (R-12).

## Критерии приёмки

- [x] Таблица «Свои поля»: колонка «Доступ AI» с компактным выбором, пояснения вариантов второй строкой в меню, значок с пояснением у заголовка — по W1.
- [x] Для Email и Телефона «Видит значение» недоступно, в меню — причина, под выбором — «только под маской».
- [x] Таблица «Поля контакта»: колонка «Доступ AI» с бейджем «Под маской» и подпись карточки — по W1.
- [x] Сохраняется `aiAccess`; приём `aiVisible` на сервере удалён. Тексты в словарях ru и en, `tsc` проходит.

## Заметки

Макет: кадр W1 в `design/baseline/Веб-чат · поля и оформление/`; записка — `design/baseline/Инструменты агента и данные клиента.md`, п. 3. Выпадающий выбор — antd с `app-dropdown`.

## Итог

Тумблер «Видит AI» в разделе «Данные с сайта» заменён выбором «Не видит / Под маской / Видит значение» по кадру W1; в «Полях контакта» появилась колонка «Доступ AI» с бейджем «Под маской» и новая подпись карточки. Форма сохраняет aiAccess, сервер больше не принимает и не отдаёт aiVisible. Проверено в окружении задачи (frontend http://localhost:20004, открыт как http://127.0.0.1:20004; api http://localhost:20002; готовность /api/v1/health/ready/ — database: true, redis: true).
