## Цель

В карточке агента появляется проверочный чат: кнопка в шапке и панель справа с тестовыми данными клиента — по кадрам G7, G8.

## Критерии приёмки

- [x] Кнопка «Проверить агента» в шапке карточки открывает панель справа — по G7.
- [x] Раскрывающийся блок «Тестовые данные клиента» с контролами по типу, пояснением и «Сбросить тестовые данные» — по G8; контролы переиспользованы из формы перед чатом, где возможно.
- [x] Вызовы инструментов в ленте панели — плашкой из задачи о плашке вызовов.
- [x] Тексты в словарях ru и en, `tsc` проходит, компоненты не больше ~200 строк.

## Заметки

Сейчас проверочного чата в интерфейсе нет вообще — только серверный адрес.

## Итог

Добавлена панель «Проверить агента» по G7/G8 с тестовыми данными клиента, историей сообщений, сбросом и общими плашками вызовов инструментов. Контролы и валидация переиспользованы с формой перед чатом; карточка агента разделена на небольшие компоненты. Коммит 13778e6b; сборки, TypeScript, 18 целевых тестов и браузерная проверка на штатном окружении прошли.
