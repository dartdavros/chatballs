## Цель

Реализовать настройки причин и политики, передачу диалога и просмотр истории поверх штатного API по утверждённым макетам.

## Критерии приёмки

- [x] Настройки причин и статусов строго следуют baseline.
- [x] Права и ошибки отображаются по действующему API без локальной подмены политики.
- [x] CRUD и отключение причины проверены браузером в штатном контуре.
- [x] Выбор получателя, причина и комментарий и журнал соответствуют baseline.
- [x] Присутствие и доступность различаются; конфликт передачи обновляет состояние без скрытого повтора.
- [x] Передача и получение уведомления проверены с реальным бэкендом.

## Заметки

Основание границ задачи: Настройки и действие передачи проверяются одним сквозным сценарием. Отдельная UI-задача сохраняет дизайн-условия и позволяет не задерживать серверную передачу.

Покрытие исходных требований:
T-093 — SPEC-0025: R-1, R-5, R-10
T-103 — SPEC-0025: R-4, R-6–R-10

Все исходные критерии приёмки перенесены дословно. При реализации сохранить применимые требования действующих спецификаций 0001, 0004, 0008, 0009, 0017 и 0018. Реализация, необходимые тесты, документация и проверка результата входят в эту же задачу.
