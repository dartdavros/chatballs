## Цель

Реализовать фоновую генерацию черновика, защищённые запросы и альтернативы, а также связь предложения с ручной отправкой сотрудника.

## Критерии приёмки

- [x] Генерация использует доступные инструкции и знания, актуальную публичную историю и общую псевдонимизацию.
- [x] Фоновый повтор не вызывает вторую логическую генерацию; ошибки и просрочка возвращают безопасное состояние.
- [x] Ни успех, ни ошибка не отправляют сообщение и не изменяют ответственного или режим диалога.
- [x] API проверяет право ответа, открытый диалог и принадлежность попытки; ключ повторного запроса возвращает ту же операцию.
- [x] Альтернативы и отклонение сохраняются без потери исходного текста и с автором решения.
- [x] Статус и результат доступны через защищённую выдачу и realtime только действующим уполномоченным сотрудникам.
- [x] Обычная отправка принимает идентификатор предложения и отредактированный текст и сохраняет оператора и время.
- [x] Ссылка на предложение другого диалога/организации отклоняется; право ответа проверяется повторно.
- [x] Повтор отправки не создаёт второе клиентское сообщение, исходное предложение сохраняется отдельно.

## Заметки

Основание границ задачи: Генерация, API и связь отправки образуют один проверяемый серверный цикл. Сервер используется редактором, но может быть завершён и проверен до утверждения макета; UI помощи остаётся отдельным.
