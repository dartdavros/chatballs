## Цель

Реализовать согласованные клиентские подтверждения, напоминания и эскалацию по правам, а также управление независимыми правилами и защищённый просмотр журнала.

## Критерии приёмки

- [x] Подтверждение использует настроенный текст и срок на языке организации через исходное подключение.
- [x] Повтор события не создаёт второй логический ответ, секреты и внутренние сведения не отправляются.
- [x] Выключенное правило и отсутствующая обязательная настройка не отправляют выдуманное сообщение.
- [x] Напоминания применяют согласованный период ожидания и отменяются при устранении условия.
- [x] Сотрудники и супервизоры выбираются по фактической области доступа, доступность учитывается только явным условием.
- [x] Идемпотентность и независимые способы доставки сохраняют штатное поведение уведомлений.
- [x] OWNER/ADMIN управляют независимыми правилами; условия и получатели валидируются сервером.
- [x] Пагинированный журнал доступен только разрешённой области, причины ошибок безопасны.
- [x] Выключение отражается в pending исполнениях, старый эффект не удаляется задним числом.
