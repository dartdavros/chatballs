## Цель

Реализовать отправку веб-ответа через штатный почтовый outbox, привязку входящего ответа к треду и защищённое API адресов, попыток и повторов.

## Критерии приёмки

- [x] Проверяются право ответа, существующий адрес и EMAIL-подключение организации.
- [x] Сообщение, операция, Message-ID и outbox сохраняются идемпотентно с фактическим транспортом.
- [x] Повтор разрешённой попытки сохраняет ящик и различает ошибку, SMTP-принятие и неизвестный исход.
- [x] Входящий адаптер передаёт In-Reply-To/References, маршрут проверяет тред, ящик и отправителя.
- [x] Повтор Message-ID не создаёт дубль; письмо без связи остаётся в обычном email-потоке.
- [x] Для завершённого обращения применяется новый связанный диалог, контакт не объединяется по email сайта.
- [x] Список адресов/ящиков, попытки и состояние посетителя ограничены текущими правами.
- [x] Повтор невозможен для чужой или уже достоверно успешной операции; секреты ошибок не раскрываются.
- [x] Обычные почтовые и веб-обращения работают по прежним контрактам, доставка подтверждается только фактом.
