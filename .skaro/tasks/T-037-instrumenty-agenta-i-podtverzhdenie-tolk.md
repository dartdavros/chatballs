## Цель

Администратор включает агенту отдельные инструменты; включить можно только «только чтение»; подтверждение для MCP-инструмента хранит, кто и когда, и пишется в журнал аудита (R-6, R-9).

## Критерии приёмки

- [x] Связь агента с инструментами хранится с организацией, под RLS, с тестом изоляции; API карточки агента отдаёт доступные и включённые инструменты, изменения применяются сразу.
- [x] Включение MCP-инструмента без `readOnlyHint` и без подтверждения, а POST без отметки «только чтение» отклоняется.
- [x] Подтверждение и его снятие сохраняют автора и время и пишутся в журнал аудита; снятие выключает инструмент у всех агентов.
- [x] Выключение или удаление внешнего сервера выключает его инструменты у всех агентов.

## Итог

На сервере добавлены связь агента с инструментами внешних серверов и подтверждение «только читает» для MCP-инструмента: обе таблицы хранятся с организацией под RLS. Карточка агента отдаёт серверы с инструментами (доступные и включённые) и принимает набор включённых в PATCH; включить можно только инструмент, который читает. Подтверждение и снятие хранят автора и время, пишутся в журнал аудита; снятие подтверждения, выключение или удаление сервера выключают инструменты у всех агентов. Только бэкенд, интерфейса в задаче нет.
