## Цель

Администратор описывает HTTP-инструмент, параметры и их источники — по кадрам X6–X8.

## Критерии приёмки

- [x] Инструмент: название, имя (моноширинно), описание для AI, включён, метод, адрес с подсветкой подстановок, отметка «только чтение» у POST, заголовки — по X6.
- [x] Параметры: строки с типом, обязательностью, местом, источником и описанием для AI; меню строки (открыть, дублировать, переместить, удалить); панель параметра; блок «Как уйдёт запрос» — по X7, X7a, X7b.
- [x] Ошибки валидации и недоступная «Сохранить» с числом ошибок — по X8.
- [x] Тексты в словарях ru и en, `tsc` проходит, компоненты не больше ~200 строк.

## Итог

Страница HTTP-инструмента приведена к макетам X6–X8: поля инструмента, секретные заголовки, параметры, меню и панель редактирования, пример запроса и ошибки с недоступным сохранением. Добавлена серверная проверка адреса без записи и вызова HTTP-инструмента; изменения сохранены коммитом b6ba2afd. Проверены штатное окружение, браузерные сценарии, сборка, tsc и профильные тесты.
