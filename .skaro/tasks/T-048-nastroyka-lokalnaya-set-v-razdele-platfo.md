## Цель

Администратор установки включает доступ инструментов к локальной сети с подтверждением и видит, кто и когда включил — по кадрам A3–A5 (R-17).

## Критерии приёмки

- [x] Карточка с переключателем и предупреждением в разделе «Платформа» — по A3; видна только администратору установки.
- [x] Включение — через окно подтверждения (A4); во включённом состоянии — «Включено · имя · когда» (A5).
- [x] Тексты в словарях ru и en, `tsc` проходит.

## Заметки

Макет: `design/baseline/Chatballs Baseline v2/Админ Baseline.dc.html`.

## Итог

В раздел «Платформа» добавлена карточка «локальная сеть» (ToolsNetworkCard) по кадрам A3–A5: переключатель, предупреждение о риске, строка «кто и когда включил», включение через окно подтверждения. Тексты добавлены в словари ru и en, клиент API — в features/settings/instance.ts. Проверено в браузере на окружении задачи (frontend http://localhost:20010, api http://localhost:20008).
