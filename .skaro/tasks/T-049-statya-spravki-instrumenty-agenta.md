## Цель

Справка объясняет подключение MCP и HTTP-запроса, привязку параметров и обязанность API организации проверять владельца данных (R-21).

## Критерии приёмки

- [x] Статья описывает оба вида внешнего сервера на примере «Статус заказа».
- [x] Отдельный раздел: данные с сайта подменяемы, API должен проверять, что заказ принадлежит клиенту.
- [x] Ссылка из блока о подменяемых данных на страницах сервера ведёт на статью.
- [x] Статья есть на ru и en.

## Заметки

Оформить так же, как статью «Классы виджета» (T-024).

Реализованы страницы MCP и HTTP по утверждённому макету, редактор параметров и предупреждения со ссылкой на справку. Двуязычная статья импортирована и опубликована в действующем центре помощи с разрешения владельца; переходы с обеих страниц проверены.
