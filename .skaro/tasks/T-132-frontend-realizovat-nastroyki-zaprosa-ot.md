## Цель

Реализовать настройку запроса, публичную форму с согласованными состояниями и отображение оценки в карточке диалога.

## Критерии приёмки

- [x] Настройки включения, шкалы, текста и срока соответствуют baseline.
- [x] Отсутствующая обязательная настройка предотвращает включение по API.
- [x] Сохранение и отключение проверены браузером на реальном бэкенде.
- [x] Форма, необязательный комментарий, успешный, повторный и просроченный результат следуют baseline.
- [x] Credential открывает только данный вопрос и не историю обращения.
- [x] Действительный и недействительный запрос проверены браузером через реальный backend.
- [x] Результат, шкала, комментарий и связанные сотрудники соответствуют baseline.
- [x] Карточка использует разрешённую выдачу, а не публичный credential.
- [x] Отсутствие оценки и доступ супервизора проверены браузером.

## Заметки

Основание границ задачи: Настройка, ответ клиента и просмотр результата проверяются одним циклом оценки; не требуют отдельных веток. UI выделен из серверной задачи из-за обязательных макетов нескольких аудиторий.

Покрытие исходных требований:

T-133 — SPEC-0032: R-4–R-6, R-10
T-134 — SPEC-0032: R-7, R-8, R-10
