## Цель

Организация хранит внешние серверы вида `mcp` и `http` с зашифрованными заголовками и управляет ими через API (R-1–R-4).

## Критерии приёмки

- [x] Новый тип интеграции с видом `mcp | http`; для `http` — один инструмент: название, имя, описание для AI, метод, шаблон адреса, параметры с источником значения, заголовки, отметка «только чтение» для POST; имя проверяется по `^[a-z][a-z0-9_]{0,39}$`.
- [x] Ошибки валидации — через словарь: неверное имя, подстановка в адресе без параметра, адрес в локальной сети.
- [x] Секретные заголовки хранятся в зашифрованных полях и не возвращаются в ответах API.
- [x] Тест изоляции: внешний сервер одной организации недоступен другой под runtime-ролью.

## Итог

Добавлен род интеграции «Внешний сервер» с видами MCP и HTTP в общей таблице интеграций: настройки приходят и отдаются в ключе externalServer существующего API /integrations/. HTTP-запрос хранится как один инструмент с параметрами и источником значения; секретные заголовки лежат в новой зашифрованной колонке secret_headers и наружу не отдаются. Ошибки настроек берутся из словаря (ru/en), возвращаются по полям и все сразу.
