## Цель

Дать законченный сценарий работы с библиотекой: создание с нуля или из готовой основы, изменение инструкции, поиск, удаление и подключение нескольким агентам. Воспроизвести K1–K6/A1–A3 с согласованными дополнениями существующей системы.

## Критерии приёмки

- [x] В разделе «Агенты» есть вкладка «Навыки» по K1, поиск/стандартная пагинация, колонки и ссылки на подключённых агентов; пустота K2 и загрузка K3. Новый пункт основного меню не появляется.
- [x] Создание и редактор используют K5/K6: обязательные поля/ограничения, локальный ввод до сохранения, выбор основы только при создании, подтверждение замены введённого, установка готовой копии только действием администратора. Шаблоны готовой копии перечислены без фиктивных данных backend.
- [x] Сохранение и удаление явно сообщают, каких агентов затронут; ошибки не теряют ввод и дают повтор. Конкурентная ревизия не перезаписывается молча, обновление данных подтверждается. Уход с изменениями обрабатывается по общему атомарному контракту.
- [x] Карточка агента показывает A1 после инструкций до знаний, сохраняя остальные блоки и их порядок; A2 позволяет выбрать несколько, уже подключённые недоступны; A3 отключает только текущего агента. Дубли при повторе не возникают.
- [x] Несовместимость/неизвестная поддержка модели, ошибки загрузки/отсутствующий объект/пустой поиск/отказ доступа и ошибки действий реализованы ровно по docs/agent-skills-ui-agreement.md существующими компонентами. Прав управления у EMPLOYEE/SUPERVISOR нет и серверный отказ корректно обработан.
- [x] Число затронутых агентов и связанные подписи динамические через tn; ссылки .link, меню antd Dropdown/app-dropdown/row-menu-button, поля и кнопки существующей системы. Служебные аннотации макета не выводятся.
- [x] Шаблоны в редакторе навыка имеют согласованный переход к редактору шаблонов; отсутствие ещё не подключённого редактора не маскируется фиктивной рабочей страницей. Полный сценарий добавления/изменения шаблона завершает зависимая задача skills-template-editor-ui.
- [x] В задачу включены RU/EN i18n, применимая сборка и только относящиеся к изменениям тесты, browser-проверка на штатном backend в обеих темах и проверка SRP/NO GOD FILES. Показанные кадры сохраняются, недостающие состояния — только по docs/agent-skills-ui-agreement.md. Никаких seed, сбросов учётных данных, fake backend или полного прогона.

## Заметки

Источники: design/baseline/agent-skills/Навыки агентов.dc.html K1–K6/A1–A3; docs/agent-skills-design.md и docs/agent-skills-ui-agreement.md обязательны. Это один административный workflow; таблица, форма, установка и привязка не дробятся. От редактора кода отделён по самостоятельному сценарию управления инструкционными навыками. Не удалять существующие блоки агента из сокращённого A-макета; не менять остальную навигацию. Baseline и документы должны присутствовать в рабочей ветке до browser-проверки.

## Итог

Реализована библиотека навыков во вкладке «Агенты», атомарный редактор с готовой основой, защитой ввода и конфликтов ревизий, подключение нескольких навыков и отключение только текущего агента. Добавлены RU/EN, согласованный контракт подключения зависимого редактора шаблонов и протокол проверки штатного backend в обеих темах; сборка, 50 frontend-тестов и 9 backend-тестов прошли.
