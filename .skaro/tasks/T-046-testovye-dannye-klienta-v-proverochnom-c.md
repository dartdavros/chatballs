## Цель

Проверочный чат принимает тестовые данные клиента и ходит по тем же правилам, что живой диалог, включая инструменты и псевдонимизацию (R-22, R-23).

## Критерии приёмки

- [x] `agent-card/{id}/test-chat/` принимает имя, e-mail, телефон и значения своих полей веб-подключений агента; значения проверяются по схеме и нигде не сохраняются.
- [x] Тестовые значения служат известными значениями псевдонимизации и источником привязанных параметров.
- [x] Ответ содержит вызовы инструментов хода (имя, результат, длительность) для показа плашкой.
- [x] Тест: проверочный чат с номером заказа вызывает привязанный HTTP-инструмент с этим номером.

## Итог

Проверочный чат принимает и проверяет clientData по схеме веб-подключений агента, использует данные для псевдонимизации и привязанных параметров и выполняет общий цикл инструментов вне транзакции. Ответ содержит метаданные вызовов для плашки; тестовые значения остаются в памяти. Коммит 7e06f891; 33 целевых теста, сборка backend, Ruff и Django check прошли.
