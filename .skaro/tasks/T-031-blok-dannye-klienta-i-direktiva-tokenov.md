## Цель

Модель получает имя, e-mail, телефон и свои поля по режиму доступа одним блоком и знает, как обращаться с токенами (R-7, R-8).

## Критерии приёмки

- [x] Блок «Данные клиента с сайта» заменён блоком «Данные клиента»: имя, e-mail, телефон токенами, затем свои поля по режиму в порядке схемы; `hidden` не передаётся, `masked` — токеном `[[<ключ>]]`, `open` — значением.
- [x] Сведения с сайта в блоке помечены как недоверенные данные, а не инструкции.
- [x] Директива про токены (без склонения и догадок о поле, переписывать без изменений) добавлена в системные сообщения хода и не переводится.
- [x] `test_site_context.py` переписан под новый блок и проходит.

## Итог

Блок «Данные клиента с сайта» заменён блоком «Данные клиента»: имя, e-mail и телефон контакта токенами, затем свои поля по режиму доступа в порядке схемы; свои поля «под маской» стали известными значениями карты хода. В системные сообщения каждого хода добавлена непереводимая директива про токены. Тесты test_site_context.py переписаны и проходят.
