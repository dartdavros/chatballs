## Цель

Предоставить один ограниченный серверный обработчик HTML/CSS/текста и API проверки/предпросмотра несохранённой конфигурации. Поставить редактируемую основу «Работа с заказами», устанавливаемую только явным действием администратора.

## Критерии приёмки

- [x] Шаблоны принадлежат навыку и имеют стабильные ID, назначение, типизированную вложенную схему, HTML, CSS и обязательный текст. Сохранение целой конфигурации с шаблонами атомарно по ожидаемой ревизии; права/RLS распространяются на шаблоны и предпросмотр.
- [x] Ограниченный язык реализует только подстановку, each и if с контекстом элемента/путями вложенных полей по R-12; неизвестные поля, неверные типы, обязательные пропуски, незакрытые блоки, код и raw HTML отвергаются. 0/false и отсутствие/null обрабатываются согласно спецификации.
- [x] Положительная политика HTML/атрибутов/URI и CSS проверяется серверным парсером: нет скриптов, обработчиков, форм, пользовательских iframe, изображений, внешних ресурсов/import/url и опасных ссылок. Нельзя воздействовать на оболочку/соседние сообщения. Переменные экранируются по контексту.
- [x] Один обработчик принимает несохранённую конфигурацию/пример и возвращает безопасные text/contentHtml/изолированное оформление либо ошибки вкладки/строки/колонки/пути; предпросмотр не применяет конфигурацию и не отправляет клиенту. Ошибочный пример отличим от ошибки самой конфигурации.
- [x] Зафиксированы конечные лимиты входа, исходников, инструкции/схемы, глубины, списков, операций и результата; ограничения проверены граничными тестами, XSS/CSS/URI-сценариями и соответствием длинному примеру из 7 позиций. Предпросмотр и runtime используют идентичную политику.
- [x] Поставляемая основа содержит инструкцию и шаблоны «Карточка заказа» и «Статус заказа», обе версии и примеры по R-30/31. Числа форматирует fmt; отсутствие eta скрывает блок. RUB не приписывается данным иной/неизвестной валюты; факты и суммы модель не выдумывает.
- [x] Явный выбор основы/сохранение создаёт редактируемую копию организации с локализацией RU/EN по её языку, без интеграций, seed, автоподключения к агентам/инструментам. Повтор запроса не дублирует установку, обновление встроенной основы не перезаписывает копии.
- [x] Инструкция готового навыка использует только уже включённые инструменты по описаниям/схемам, уточняет недостающий номер, при невозможности ответить передаёт человеку, запрещает изменение заказа и объясняет внешнюю проверку принадлежности. Дизайн-примеры не становятся рабочими ответами.
- [x] В задачу включены документация контракта, сборка/применимые проверки проекта и только тесты изменённого поведения с --reuse-db; полный прогон запрещён. Проверены SRP/NO GOD FILES. Штатные сервисы, без seed, сброса учётных данных и подменного API.

## Заметки

Основание: ADR-0036; SPEC-0035; baseline/agent-skills T1–T3/W1–W4. Серверный обработчик и готовая основа объединены: основа является проверяемым потребителем этого обработчика, не отдельной моделью заказов. Выделено отдельно для самостоятельного контроля безопасности и возможности работы параллельно с инструкционным runtime. Полные пользовательские исходники готовых карточек в архиве отсутствуют: создать их по визуальному baseline внутри этой реализации; не зашивать карточку заказа в React. Здесь нет реального вызова внешнего сервера при предпросмотре.
