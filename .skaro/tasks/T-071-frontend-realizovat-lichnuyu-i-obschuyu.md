## Цель

Реализовать личную и общую библиотеку с поиском, категории, теги и редактор, а также выбор и подстановку шаблона в сообщение.

## Критерии приёмки

- [x] Разделение областей, список и поиск соответствуют baseline.
- [x] Управление доступно по фактическим правам; чужие личные шаблоны не появляются.
- [x] Создание, изменение и удаление обеих областей проверены браузером.
- [x] Редактор и управление категорией/тегами соответствуют baseline.
- [x] Переменные берутся из серверного каталога, ошибка сохранения показывает проблему по словарю.
- [x] Удаление категории сохраняет шаблон; вставка переменной в редактор проверена браузером.
- [x] Выбор и поиск из редактора сохраняют согласованные «/» и прежний поток вставки.
- [x] Подстановки используют API; незаполненные значения блокируют UI и серверную отправку.
- [x] Вставка, правка и реальная отправка проверены браузером.

## Заметки

Основание границ задачи: Библиотека, редактирование и вставка образуют один пользовательский цикл шаблона и опираются на уже поставленные на проверку серверные задачи.
