## Цель

Провайдеры передают модели инструменты и принимают `tool_calls`; известно, поддерживает ли модель инструменты (R-10, R-14).

## Критерии приёмки

- [x] `ChatMessage` и `ChatResult` поддерживают `tool_calls` и роль `tool`; `chat_completions` передаёт `tools`.
- [x] Признак поддержки: OpenRouter — из `supported_parameters` модели, свой endpoint — из проверочного вызова; результат кешируется и отдаётся в карточке агента.
- [x] Демо-провайдер детерминированно вызывает инструмент и отвечает по результату без сети и ключей.
- [x] Тесты провайдеров на запрос с инструментами и разбор `tool_calls` проходят.

## Заметки

`ai/provider/base.py`, `openai_http.py`, `openrouter.py`, `demo.py`.

## Итог

Провайдеры принимают список инструментов и возвращают tool_calls: типы ToolSpec/ToolCall, роль tool, формат OpenAI в provider/openai_tools.py. Признак «модель вызывает инструменты» отдаёт провайдер (OpenRouter — каталог, свой endpoint — проверочный вызов), ai/tool_support.py кеширует его, карточка агента отдаёт полем modelSupportsTools. Демо-провайдер детерминированно вызывает подходящие инструменты и отвечает по их результатам.
