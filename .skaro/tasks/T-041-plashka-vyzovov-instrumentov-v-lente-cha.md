## Цель

Оператор видит вызовы одного хода одной плашкой, раскрываемой в список, с выделением ошибок — ровно по кадру T (R-20).

## Критерии приёмки

- [x] Один вызов — «Агент запросил «…» · 0,4 с · 17:02»; несколько — «Агент запросил N инструментов · 1,1 с», раскрывается в список с длительностью каждого — по кадру T.
- [x] Есть ошибка — плашка цвета ошибки с текстом ошибки или «N с ошибкой».
- [x] Компонент плашки переиспользуемый (нужен и проверочному чату), тексты через словари ru и en, числа через `tn`, `tsc` проходит.

## Заметки

Макет: кадр T в `design/baseline/Chatballs Baseline v2/Чат сотрудника Baseline.dc.html`.

## Итог

Вызовы инструментов одного хода отображаются общей раскрываемой плашкой по кадру T, с суммой длительностей и выделением ошибок. Компонент вынесен в shared для повторного использования проверочным чатом; добавлены словари ru/en и профильные тесты. Проверка выполнена на штатном окружении задачи с существующими данными, изменения закоммичены в b166f44f.
