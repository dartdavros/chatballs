## Цель

Реализовать управление условиями, сроками, получателями и текстом правил, а также просмотр их фактического исполнения, пропусков и ошибок.

## Критерии приёмки

- [x] Настройки условий, сроков, получателей и текста строго следуют baseline.
- [x] Каждое правило включается отдельно, UI не вводит условия вне серверного каталога.
- [x] Настройка и выключение проверены браузером со штатными worker и API.
- [x] Журнал и состояния выполнения, пропуска и ошибки соответствуют baseline.
- [x] Фильтры и детали не расширяют серверную область доступа.
- [x] Фактическое выполнение и отмена проверены браузером в штатном контуре.

## Заметки

Основание границ задачи: Настройка правила и проверка его выполнения — один UI-цикл; оба используют готовое API и общие дизайн-условия. Сервер не задерживается из-за ожидания макета.

Покрытие исходных требований:
T-151 — SPEC-0034: R-1, R-2, R-11
T-152 — SPEC-0034: R-9, R-11
