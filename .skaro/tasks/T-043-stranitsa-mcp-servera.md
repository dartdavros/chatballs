## Цель

Администратор настраивает MCP-сервер, обновляет список инструментов и подтверждает «только читает» — по кадрам X2–X5.

## Критерии приёмки

- [x] Подключение: включён, название, описание, адрес, заголовки с «•••• сохранено · Заменить», «Сохранить», «Проверить соединение», статус — по X2.
- [x] Инструменты: «Обновить список инструментов», дата, бейджи «Только чтение» / «Может изменять данные», «Подтвердить, что только читает», отметка «Только чтение подтверждено · имя, дата», снятие в меню — по X2–X3.
- [x] Окно подтверждения с обязательным флажком «Подтверждаю: инструмент только получает данные» — по X4.
- [x] Все состояния X5, при ошибке прежний список приглушён с датой; тексты в словарях, `tsc` проходит.

## Заметки

Окно — существующий `DecisionDialog`; меню — antd `Dropdown` с `app-dropdown`.

## Итог

Страница MCP-сервера приведена к X2–X5: состояние соединения, список инструментов и дата обновления, подтверждение через DecisionDialog с обязательным флажком и снятие через app-dropdown. Исправлены состояния ошибок и обновления, сохранение прежнего списка с датой, оформление и тексты в русском и английском словарях; изменения сохранены коммитом ddc050fc.
