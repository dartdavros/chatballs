## Цель

Устранить сквозные расхождения с утверждённым дизайном platform-expansion от 10.10.2026: обновить левую навигацию и логотип Chatballs, привести все существующие обозначения агента к актуальному знаку и добавить ссылку «Помощь». Получить единое оформление общих элементов во всех разделах без изменения бизнес-логики и прав доступа.

## Критерии приёмки

- [x] Левое меню владельца/администратора воспроизводит макет «Сотрудники и агенты.dc.html»: Чат, Контакты, Агенты, Сотрудники, Порталы, База знаний; разделитель перед Статистикой; затем Статистика, Настройки, Помощь. Геометрия, отступы, типографика, иконки и активные/hover-состояния соответствуют HTML. Иконка Статистики — четыре одинаковые плитки из константы STATS макета вместо нынешнего неравномерного grid; общая grid-иконка в других смыслах не меняется автоматически.
- [x] У сотрудника и супервизора навигация чата соответствует «Чат · совмещённые кадры.dc.html»: после дерева диалогов расположен разделитель и «Помощь», перед ней Статистика только при действующем праве просмотра. Сохраняются отдельная роль SUPERVISOR и согласованные ограничения доступа из INTEGRATION.md; меню не выдаёт дополнительных прав и не скрывает доступные действия.
- [x] Пункт «Помощь» оформлен по HTML: circle-help слева, малая стрелка внешней ссылки справа, правильные размеры и состояния. Это настоящая ссылка на https://chatballs.com.edevs.tech/ с target="_blank" и безопасным rel, работающая с клавиатуры. Адрес берётся из общего shared/help.ts через общий экспорт/функцию, без дублирования строк URL по компонентам; текст и подсказка присутствуют в русской и английской i18n.
- [x] Стандартный логотип Chatballs использует точную векторную графику assets/logo-sunset.svg: градиенты, форма и пропорции сохранены; в шапке меню ширина знака 28px, высота по пропорциям макета, без старого монохромного варианта и квадратного искажения. Проверены полное меню, узкая рейка и мобильное раскрытие. Пользовательский логотип организации продолжает работать.
- [x] Обновление стандартного логотипа выполнено через общий переиспользуемый ресурс/компонент во всех существующих местах брендинга Chatballs, включая AuthFrame, онбординг и HelpLayout; проверен favicon. Контекстные размеры и утверждённые состояния сохраняются, новые экраны и варианты оформления не придумываются. Независимая анимация Loader не перепроектируется в рамках этой задачи.
- [x] Во всём internal-ui используется точная контурная геометрия I.robot из platform-expansion/chat-model.js без моргания: меню и дерево агентов, список/карточка агента и пустое состояние, фильтры диалогов, заголовок/сообщения/карточка диалога, контакты и их диалоги, подключения, знания, привязки материалов и статьи порталов. Старый путь робота удалён из продуктового использования; актуальный знак имеет один общий источник. Размеры, цвета агента и контекстные состояния сохранены по соответствующим макетам.
- [x] Проверены также packages/ui/BotIcon, apps/web-chat и предпросмотр виджета: используется согласованная форма бота без возврата к старому роботу. Контурное отображение внутреннего приложения и предусмотренные baseline заливка/моргание клиентского виджета не смешиваются произвольной глобальной заменой; свои загруженные иконки и режим «Без иконки» продолжают работать. Все затронутые варианты сверены с их действующими макетами.
- [x] Браузерная проверка проведена в штатном контуре с реальным backend и существующими учётными записями: владелец/администратор, сотрудник и супервизор; светлая/тёмная темы, desktop, узкая рейка и мобильное раскрытие по кадрам K6 и M1–M2. Сохранены сравнительные скриншоты ключевых элементов и перечень проверенных мест использования; переход «Помощь» открывает ожидаемую справку. При недоступности штатного окружения проверка отмечена заблокированной, без mock API, seed и сброса доступа.
- [x] Выполнены проверки только затронутых сценариев: доступность/видимость навигации по ролям, переход в справку и регрессии общих иконок/логотипа; i18n проверен для новых ключей. Для чисто визуальных мелких правок сборка автоматически не запускается; если изменяется логика компонентов или экспортов — проходит сборка затронутых пакетов. Полный набор тестов не запускается.
- [x] Изменения соответствуют DRY, SRP и NO GOD FILES: общие элементы не копируются по разделам; при росте существующих больших shared/icons.tsx или layout/styles.css новые ответственность и стили вынесены в небольшие модули. Все отличия от HTML ограничены уже согласованными исключениями INTEGRATION.md; обязательное отсутствующее дизайн-состояние вынесено владельцу до реализации.

## Заметки

Основание: сравнение актуальных исходников и HTML baseline, без изменения файлов и без утверждения о проведённой live browser-проверке. Подтверждено: shared/icons.tsx содержит старый LogoIcon с currentColor и старый путь robot (M6 6a2…), layout/Sidebar.tsx не содержит ссылки «Помощь», Статистика использует grid с неравными плитками; layout/styles.css растягивает знак в квадрат 26×26. Новый макет содержит assets/logo-sunset.svg, I.robot (M7 4.6…), STATS с четырьмя одинаковыми плитками и ссылку справки. Источники истины: design/baseline/platform-expansion/INTEGRATION.md, «Сотрудники и агенты.dc.html» G1–G3/E1–E4, «Чат · совмещённые кадры.dc.html» K1/K6/K7–K9/M1–M2, «Настройки · новые разделы.dc.html», chat-model.js и assets/logo-sunset.svg; для клиентского виджета — его действующий baseline. Основные точки: layout/{Sidebar,OrganizationSwitcher,ChatScopeTree}.tsx, shared/{icons.tsx,help.ts}, features/{agents,conversations,ai/knowledge,integrations,sales,support-portals}, features/{auth,onboarding,help-center}, packages/ui/src/BotIcon.tsx, apps/web-chat/src/BotIcon.tsx. Это одна связная корректировка дизайна существующих элементов, без нового этапа и спецификации; невыполненных зависимостей нет. Не перепланировать и не расширять завершённые T-051/T-060/T-113/T-144. Не менять backend, данные, роли или настройки установки. Учесть существующие чужие незакоммиченные изменения; правила коммитов — по проекту.
