## Цель

Дать владельцу и администратору проверяемый API общей библиотеки инструкционных навыков организации и явного подключения нескольким агентам. Реализовать целостность, поиск, ревизию и аудит без изменения штатных ответов AI.

## Критерии приёмки

- [x] Навык хранит стабильный ID, название 1–60, условие применения 1–200, непустую инструкцию, автора/время и техническую ревизию; API создаёт, читает, атомарно изменяет и удаляет конфигурацию; навык без шаблонов валиден.
- [x] Список поддерживает серверный поиск по названию/описанию и стандартную пагинацию; возвращает подключённых агентов и предусмотренные метаданные. Публичные API виджета не открывают библиотеку.
- [x] Явные подключения к агентам одной организации уникальны; повтор не создаёт дубль; отключение затрагивает только выбранного агента. Удаление возвращает сведения для подтверждения и удаляет текущие связи, сохраняя историю.
- [x] OWNER/ADMIN могут управлять; EMPLOYEE/SUPERVISOR и чужая организация не могут. Связи защищены сервисами, ограничениями БД и RLS; изоляция проверена под реальной runtime-ролью.
- [x] Ожидаемая ревизия предотвращает тихую конкурентную перезапись; ошибки имеют безопасные структурированные коды. Аудит содержит действие/исполнителя/ID, без инструкций, шаблонов и клиентских данных.
- [x] Контракт атомарной конфигурации допускает последующее добавление шаблонов; частично валидная конфигурация не публикуется. Создание защищено от дубля при повторе одного запроса.
- [x] В задачу включены документация контракта, сборка/применимые проверки проекта и только тесты изменённого поведения с --reuse-db; полный прогон запрещён. Проверены SRP/NO GOD FILES. Штатные сервисы, без seed, сброса учётных данных и подменного API.

## Заметки

Основание: ADR-0036; SPEC-0035; docs/agent-skills-design.md и docs/agent-skills-ui-agreement.md. Отдельный результат — административный API и изоляция библиотеки; от него независимо зависят runtime и обработчик шаблонов. Здесь нет UI, загрузки навыков моделью, создания встроенного заказа и задач на планирование. Новая схема допускает относящиеся к ней миграционные проверки; полный прогон не нужен.

## Итог

Реализована административная библиотека навыков организации с атомарной конфигурацией, поиском, пагинацией, явными подключениями к агентам, ревизиями и идемпотентным сохранением. Добавлены RLS, ограничения целостности, безопасные ошибки и аудит, документация контракта; штатный runtime AI и UI не изменялись. Коммит b8acd30d; целевые проверки завершились 19 passed.
