## Цель

HTTP-инструмент собирает запрос из шаблона и аргументов; привязанные параметры подставляет сервер из данных клиента (R-3, R-4).

## Критерии приёмки

- [x] Параметры подставляются в путь (с URL-кодированием), query или тело JSON; итоговый адрес проверяется политикой исходящего клиента.
- [x] Привязанный параметр берётся из имени, e-mail, телефона контакта или своего поля веб-подключения диалога и не попадает в схему для модели.
- [x] Если обязательного привязанного значения нет (в том числе вне веб-виджета для своего поля), инструмент в ходе не предлагается.
- [x] Тесты: подстановка, привязка к своему полю, попытка внедрить внутренний адрес через параметр.

## Итог

Добавлен модуль integrations/http_tool.py: он собирает запрос HTTP-инструмента из шаблона адреса, аргументов модели и привязанных значений (путь с URL-кодированием, query, тело JSON) и отправляет его через защищённый исходящий клиент. Слой ai/tool_bindings.py берёт данные клиента из контакта и своих полей веб-подключения диалога и отдаёт описание инструмента для модели без привязанных параметров либо None, если обязательного значения нет. К циклу хода агента это ещё не подключено — цикла с инструментами в ветке пока нет, это отдельная задача этапа.
