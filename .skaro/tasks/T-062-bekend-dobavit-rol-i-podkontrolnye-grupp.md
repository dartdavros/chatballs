## Цель

Добавить роль и подконтрольные группы. Реализовать серверную часть с самостоятельной приёмкой без нового UI.

## Критерии приёмки

- [x] Фиксированная роль и отдельные связи области реализованы по принятому ADR.
- [x] Управление доступно OWNER/ADMIN, существующие роли и членство в группах сохранены.
- [x] Изменения роли и области аудируются, payload не раскрывает секреты.

## Заметки

Ключ плана: B13.1; этап M13; SPEC-0029, R-1, R-2, R-8. Источник разбивки: .skaro/docs/platform-expansion-task-plan.md.
Условия запуска (обязательные): Принят ADR о фиксированной роли супервизора.
Нерешённые продуктовые решения согласуются в проектном чате владельцем; coding-агент не готовит спецификации и не планирует другие задачи. Проверить перечисленные условия до запуска.
Следовать действующим архитектуре, ADR и AGENTS.md: tenant-изоляция, существующие сервисы, i18n, псевдонимизация AI, DRY/SRP и NO GOD FILES. Не менять учётные данные, не запускать seed или заглушки ради проверки. Сборка по правилам владельца, только относящиеся к изменениям тесты; --reuse-db при неизменной схеме, без полного прогона. Не выполнять изменения вне ответственности этой задачи.

## Итог

Добавлена фиксированная роль SUPERVISOR и отдельная tenant-связь подконтрольных групп по принятому ADR-0033. OWNER/ADMIN управляют ролью и областью через существующий API сотрудников; отзыв области, удаление группы и передача владения аудируются без секретов, обычное членство сохранено. Приёмка бэкенда выполнена без нового UI в штатном окружении задачи, коммит 7b8fd8b1.
