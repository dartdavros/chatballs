## Цель

Реализовать CRUD и поиск доступных шаблонов. Реализовать серверную часть с самостоятельной приёмкой без нового UI.

## Критерии приёмки

- [x] Личные доступны только владельцу, общие редактируются по отдельному разрешению.
- [x] Пагинированный поиск по названию/тексту и фильтры категорий/тегов не раскрывают чужие данные.
- [x] Удаление категории или тега сохраняет шаблоны; прямые IDs проверяются по области.
