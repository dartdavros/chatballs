## Цель

Реализовать единый расчёт базовых показателей, нагрузки и времени по статусам, защищённые фильтры API и согласованные экспорты CSV и XLSX.

## Критерии приёмки

- [x] Счётчики и интервалы следуют утверждённым формулам, включая передачу и серии клиентских сообщений.
- [x] Фильтры периода, сотрудника, группы и подключения применяют исторические измерения и текущий доступ.
- [x] Неполная история явно обозначается; недоступные значения не превращаются в ноль, внутренний комментарий не считается ответом.
- [x] Нагрузка соответствует текущим открытым назначениям, а не количеству добавленных участников.
- [x] Длительности статусов вычисляются пересечением интервалов с периодом и не восстанавливаются из presence.
- [x] Чужие сотрудники исключены из командной выдачи, соблюдена согласованная политика блокировки.
- [x] CSV использует тот же расчёт, фильтры, доступ и полноту, что API.
- [x] Файл содержит период, часовой пояс и единицы; пользовательские значения не интерпретируются как формулы.
- [x] Экспорт проверен на реальных данных штатной базы без изменения этих данных.
- [x] XLSX использует единый расчёт и соответствует значениям API для тех же параметров.
- [x] Числовые значения, единицы, период и признаки отсутствия представлены без подмены пропусков нулями.
- [x] Права и защита формульной интерпретации действуют для всех листов и деталей.

## Заметки

Основание границ задачи: Оба экспорта используют тот же расчёт и права, поэтому входят в задачу показателей. Базовые показатели нужны анализу качества и не должны ждать клиентских оценок или отчётного дизайна.
