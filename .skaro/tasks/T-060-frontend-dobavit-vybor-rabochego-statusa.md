## Цель

Реализовать выбор рабочего статуса и его отображение отдельно от присутствия в справочнике и рабочих элементах с realtime-обновлением.

## Критерии приёмки

- [x] Выбор четырёх статусов и состояния сохранения соответствуют baseline.
- [x] Отображается фактически сохранённый статус конкретной организации.
- [x] В браузере проверено изменение без подмены присутствия и без изменения другого membership.
- [x] Справочник и рабочие элементы отображают две характеристики по baseline.
- [x] Realtime обновляет статус и время; потеря связи не выдаётся за рабочую недоступность.
- [x] Браузерная проверка использует текущие серверные значения.

## Заметки

Основание границ задачи: Выбор и отображение одного статуса составляют единый UI-результат; отдельные ветки для них не нужны.

Покрытие исходных требований:
