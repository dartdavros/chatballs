## Цель

Реализовать фоновый анализ с проверкой оснований, временные факты из общего расчёта, API настройки и запуска, версионные корректировки и защищённую выдачу.

## Критерии приёмки

- [x] Модель использует провайдер агента обращения, публичную историю и общий слой псевдонимизации.
- [x] Оценки и ссылки валидируются по критериям и сообщениям данного диалога; невалидный результат не объявляется успехом.
- [x] Повтор worker не создаёт повторный анализ и не уничтожает исходный вывод.
- [x] Время и скорость приходят из общего расчёта событий, а не из предположений модели.
- [x] Настройки и запуск ограничены правами и не выбирают чужого провайдера при ошибке.
- [x] Недоступная историческая база и ошибка анализа возвращаются явными состояниями.
- [x] Корректировка сохраняет отдельную ревизию и причину, конфликт версии не затирает новое решение.
- [x] API выдаёт исходное и действующее значения, основания, рекомендации и историю по разрешённой области.
- [x] Фильтры и ссылки на сообщения не раскрывают чужие обращения, отчётный источник сохраняет версии шкал.
