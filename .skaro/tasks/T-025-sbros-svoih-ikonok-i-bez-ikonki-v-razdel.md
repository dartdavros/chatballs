## Цель

Сейчас загруженную иконку кнопки или шапки нельзя убрать. Добавить «Сбросить» и «Без иконки» по SPEC-0021 R-12.

## Критерии приёмки

- [x] У иконки кнопки при загруженной своей иконке рядом с «Загрузить» есть «Сбросить»; после нажатия предпросмотр показывает стандартный знак, после сохранения `launcherIcon` пустой.
- [x] У иконки шапки есть «Без иконки» (сохраняется `headerIcon: null`, шапка виджета и предпросмотр без иконки) и «Сбросить» (сохраняется пустое значение — как у кнопки).
- [x] Кнопки — `<button className="link is-muted">`, тексты в словарях ru и en, `tsc` проходит.
- [x] Виджет и предпросмотр корректно показывают шапку без иконки; тесты `appearance/model.test.ts` и `widgetAppearance.test.tsx` дополнены и проходят.

## Заметки

Макет: кадры W3 (интерактивный) и W3a (стандартная · своя · без иконки) в `design/baseline/Веб-чат · поля и оформление/`; пояснение — `design/baseline/Инструменты агента и данные клиента.md`, п. 1. Состояние «без иконки»: плитка с перечёркнутым кругом и подписью «Без иконки · В шапке только название агента»; в предпросмотре шапка без знака, название от левого края. Файлы: apps/internal-ui/src/features/integrations/appearance/IconSettings.tsx, AppearancePreview.tsx, model.ts; apps/web-chat/src/ChatHeader.tsx, widgetAppearance.ts. Сервер уже принимает пустой `launcherIcon` и `headerIcon: null` (webchat/appearance.py) — проверить тестом, менять только при необходимости.

## Итог

В разделе «Оформление» у иконки кнопки появилась ссылка «Сбросить», у иконки шапки — «Без иконки» и «Сбросить»; плитка, подписи и подсказки меняются по состоянию, как в кадрах W3 и W3a, предпросмотр показывает шапку без знака. Сервер и код виджета не менялись — добавлены только тесты. Проверено в окружении задачи skaro-chatballs-t-025 (frontend http://localhost:20004, api http://localhost:20002, web_chat http://localhost:20005) под демо-учёткой администратора на подключении «Web Chat · atelie-nord.ru». Отходы от макета: в подписи своей иконки нет имени файла и размера (согласовано), ссылки серые `link is-muted` по критерию 3, а не акцентные.
