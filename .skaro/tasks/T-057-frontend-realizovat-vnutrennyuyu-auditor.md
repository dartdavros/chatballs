## Итог

Редактор диалога получил явный выбор аудитории (вкладки «Ответ клиенту» / «Комментарий» с подписью получателя), а внутренние комментарии встали в общую ленту по времени и приходят по событию comments.changed — всё по кадрам C1–C4, K1–K2, M1 baseline platform-expansion. Комментарий сохраняется через API внутренних комментариев с ключом идемпотентности, ответ клиенту — прежним маршрутом сообщений. По решению владельца API комментария дополнен полем author.avatarUrl, чтобы в ленте было фото автора, как в макете.
