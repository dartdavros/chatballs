## Цель

Реализовать API и realtime внутренних комментариев. Реализовать серверную часть с самостоятельной приёмкой без нового UI.

## Критерии приёмки

- [x] Создание требует явной аудитории, права на диалог и идемпотентного ключа.
- [x] Защищённая история сохраняет автора и время, не переписывая предыдущие записи.
- [x] Realtime учитывает текущие права, в том числе отзыв роли и участия, и не доставляется клиентам.

## Итог

Реализованы защищённые POST/GET API внутренних комментариев с явной аудиторией, валидацией, отдельной пагинацией и конкурентно безопасной идемпотентностью. Realtime после коммита адресован только сотрудникам с заново проверенным доступом, учитывает отзыв роли, membership, группы, назначения и участия; клиентские и AI-пути остаются закрыты. Самостоятельная серверная приёмка без нового UI: сборка, Django check, Ruff и 44 относящихся к задаче теста прошли; коммит a3a3ff6b, рабочее дерево чистое.
