## Цель

Признак `aiVisible` заменяется режимом `hidden | masked | open` с проверками и переносом существующих настроек (R-10, R-11, R-13).

## Критерии приёмки

- [x] Схема поля хранит `ai_access`; `open` для типов `email` и `phone` отклоняется понятной ошибкой через словарь.
- [x] Миграция данных переводит `ai_visible` по правилу R-11 во всех WEB-подключениях всех организаций.
- [x] API настроек подключения отдаёт и принимает `aiAccess`; пока интерфейс не переведён, принимается и `aiVisible` с переводом по R-11.
- [x] Публичная конфигурация виджета режим доступа не отдаёт.
- [x] Тесты `test_web_fields.py` и `test_site_fields.py` обновлены и проходят.

## Заметки

`webchat/field_schema.py`, `ai/site_context.py`.

## Итог

Признак «Видит AI» своего поля WEB-подключения заменён режимом доступа ai_access (hidden | masked | open) с проверками, ошибками из словаря ru/en и миграцией данных по R-11. API настроек отдаёт и принимает aiAccess, а до перевода интерфейса принимает и отдаёт aiVisible; публичная конфигурация виджета режим не отдаёт. Блок промпта пока передаёт поля masked и open значением, как раньше — токены для masked делает T-031.
