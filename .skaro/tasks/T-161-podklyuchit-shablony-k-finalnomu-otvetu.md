## Цель

Довести выбор шаблона и структурированных данных моделью до единственного безопасного финального сообщения в штатном контуре AI. Сохранять самодостаточный снимок и отдавать его разрешённым потребителям, отправляя текст в остальные транспорты.

## Критерии приёмки

- [x] Загрузка навыка возвращает назначения/схемы его шаблонов, не исходники HTML/CSS. Внутренняя подготовка принимает только шаблон загруженного подключённого навыка из снимка хода и не выполняет отправку.
- [x] Известные токены восстанавливаются в данных до окончательной проверки/контекстного экранирования и очистки; типы схемы соблюдаются, неизвестные/искажённые токены и потерянные обязательные значения не уходят клиенту. Ошибки допускают только ограниченную коррекцию в общем бюджете.
- [x] Штатное завершение выбирает либо обычный текст, либо один подготовленный шаблон; промежуточные вызовы не порождают сообщений, модель не переписывает HTML. Сохраняется тот же ответ, что будет доставлен.
- [x] Message.text/content_html дополняются версией формата, изолированным оформлением, фактическим представлением и безопасными метаданными шаблона/ревизии на момент отправки. Отдельный JSON аргументов, внешние результаты и карта восстановления не сохраняются.
- [x] Снимок не зависит от живой ссылки на навык/шаблон; после их изменения/удаления текст, HTML/CSS, подписи и смысл доставки прежние. История AI использует text с повторной псевдонимизацией.
- [x] Веб-доставка получает HTML-снимок; Telegram/MAX/VK/email — сохранённый текст штатным транспортом. Выбор учитывает почтовое продолжение веб-обращения, а не только исходное подключение. Повтор доставки не пересобирает по новому шаблону и не создаёт второй логический ответ.
- [x] Перехват человеком, отмена и срок хода проверены перед фиксацией; позднее сообщение не уходит. Ошибки/передача оператору и существующие доменные события продолжают штатный жизненный цикл.
- [x] Публичные и внутренние контракты, WebSocket-обновления и проверочный чат возвращают разрешённый снимок; публичная сессия не видит другие диалоги/аудитории и конфигурацию навыка. Старые сообщения и HTML входящей почты не меняют семантику.
- [x] Готовый навык по реальным разрешённым источникам использует карточку/статус; при отсутствии источника/данных не подменяет их примерами. Проверочный чат использует тот же путь без создания клиентских сущностей.
- [x] В задачу включены документация контракта, сборка/применимые проверки проекта и только тесты изменённого поведения с --reuse-db; полный прогон запрещён. Проверены SRP/NO GOD FILES. Штатные сервисы, без seed, сброса учётных данных и подменного API.

## Заметки

Основание: ADR-0036; SPEC-0035; дополнения SPEC-0001/0008/0023. Точки: ai/turn.py, test_chat_views.py, conversations/ai_turn_result.py, ai_delivery.py, message_models.py, serializers.py, webchat/message_history.py. Выделено как один целостный workflow завершения/хранения/доставки; эти части не разделять, иначе нельзя проверить неизменяемость снимка и отсутствие поздней отправки. Здесь серверные контракты, не UI сообщений.

## Итог

Шаблоны подключены к общему завершению живого и проверочного AI-хода: сервер готовит один безопасный ответ, сохраняет самодостаточный снимок и фактический маршрут доставки. Добавлены повторная доставка сохранённого ответа, защита от поздней фиксации, разрешённые контракты истории и документация; коммит f777176b. По прямому указанию владельца готовый навык проверен без реальных доступов, в изолированных тестах штатного runtime; внешние API и учётные данные не использовались.
