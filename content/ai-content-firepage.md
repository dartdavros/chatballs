# Edevs AI — контент агента: FirePage

Задание на контент для агента канала **firepage-sales**. Заполненный результат
(по разделу «Формат ответа») вернёшь — я загружу в систему и протестируем.

## Как устроено (коротко)

- **Промпты** — роль и поведение агента: `SYSTEM`, `QUALIFICATION`, `SALES_BEHAVIOR`, `OPERATOR_HANDOFF`.
- **Знания** — база для ответов (retrieval). Категории: `OVERVIEW`, `AUDIENCE`, `COMMERCIAL`, `TECHNICAL`, `FAQ`, `OBJECTIONS`, `LIMITATIONS`.
  `inclusion`: `MANDATORY` — всегда в контексте; `RETRIEVAL` — по релевантности.

**Стиль**: простой текст для мессенджера, по-русски, без markdown (без `#`, `**`, списков `-`, `---`), кратко и по делу. Только реальные факты, без выдумок.

## Зафиксированные факты по FirePage (используй, не противоречь)
- FirePage — **готовые нишевые сайты** на собственной CMS. Модель: **один готовый сайт — одна разовая лицензия** (без подписки).
- Примеры готовых сайтов (ниша «бьюти»): **BeautySoft**, **BeautyBarbiecore**, **Beauty Tiffany** — каждый по **₽4 900** (разовая лицензия).
- Оплата/чек/выдача лицензии — в бэкенде продукта. Агент **оплату не проводит**, заказ не оформляет; при готовности — даёт следующий шаг или передаёт оператору.

> Если данных не хватает (полный каталог сайтов, что входит в лицензию, перенос контента, домен/хостинг, правки дизайна) — отметь, где нужны уточнения от меня, не выдумывай.

## Что подготовить (11 документов)

### Промпты (канал firepage-sales)
- `system-firepage` — SYSTEM. Кто агент (sales-ассистент FirePage, готовые сайты, разовая лицензия), тон, рамки, что НЕ делает.
- `qualify-firepage` — QUALIFICATION. Вопросы: ниша/тематика бизнеса, что нужно от сайта, есть ли свой контент/домен, бюджет/сроки.
- `sales-firepage` — SALES_BEHAVIOR. Помочь выбрать подходящий готовый сайт под нишу, объяснить «лицензия = сайт ваш», довести до покупки.
- `handoff-firepage` — OPERATOR_HANDOFF. Когда передавать оператору (индивидуальные доработки, счёт/юрлицо, жалоба, вопрос вне базы).

### Знания (FirePage)
- `firepage-overview` — OVERVIEW / MANDATORY. Что такое FirePage и модель «готовый сайт = разовая лицензия».
- `firepage-audience` — AUDIENCE / RETRIEVAL. Для кого готовые сайты, какие ниши подходят.
- `firepage-catalog` — COMMERCIAL / MANDATORY. Каталог готовых сайтов (названия, тематика, цена), как устроена лицензия (что покупает клиент).
- `firepage-technical` — TECHNICAL / RETRIEVAL. CMS, что входит в лицензию, что можно менять/настраивать, домен/хостинг, перенос контента (если есть — иначе пометь «уточнить»).
- `firepage-faq` — FAQ / RETRIEVAL. Частые вопросы и короткие ответы.
- `firepage-objections` — OBJECTIONS / RETRIEVAL. Возражения (готовый = не уникальный; дорого; хочу свой дизайн) и корректные ответы.
- `firepage-limitations` — LIMITATIONS / RETRIEVAL. Ограничения готовых сайтов / лицензии (что не входит, что нельзя).

## Формат ответа (строго)

Верни **один Markdown-файл**. Каждый документ — секция:

```
=== code ===
<содержимое простым текстом>
```

Правила:
- `code` — ровно из списка выше (11 штук), ничего не добавлять, не переименовывать, не пропускать.
- Между секциями — пустая строка; содержимое может быть в несколько абзацев.
- Внутри — простой текст, без markdown-разметки.
- Только `=== code ===` + текст; метаданные не нужны.
