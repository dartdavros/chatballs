# Edevs AI — контент агента: FoxRay

Задание на контент для агента канала **foxray-sales**. Заполненный результат
(по разделу «Формат ответа») вернёшь — я загружу в систему и протестируем.

## Как устроено (коротко)

Агент отвечает на основе:
- **Промптов** — роль и поведение («компетенции»): `SYSTEM`, `QUALIFICATION`, `SALES_BEHAVIOR`, `OPERATOR_HANDOFF`.
- **Знаний** — база для ответов (retrieval). Категории: `OVERVIEW`, `AUDIENCE`, `COMMERCIAL`, `TECHNICAL`, `FAQ`, `OBJECTIONS`, `LIMITATIONS`.
  `inclusion`: `MANDATORY` — всегда в контексте; `RETRIEVAL` — по релевантности вопроса.

**Стиль**: простой текст для мессенджера, по-русски, без markdown (без `#`, `**`, списков `-`, `---`), кратко и по делу. Только реальные факты, без выдумок.

## Зафиксированные факты по FoxRay (используй, не противоречь)
- FoxRay — сервис для **ортодонтов**, распространяется **по подписке**.
- Тарифы:
  - **Бесплатный** — до 3 пациентов, базовые расчёты, история; PDF без брендирования.
  - **Про** — **₽4 900/мес** или **₽47 040/год**; безлимит пациентов, брендирование клиники, приоритетная поддержка.
  - **Макс** — всё из Про + AI-расстановка точек, ранний доступ; статус «скоро».
- Оплата/чек/выдача — в бэкенде продукта. Агент **оплату не проводит**, заказ не оформляет; при готовности к покупке — даёт следующий шаг или передаёт оператору.

> Если каких-то данных не хватает (возможности, интеграции, конкретные FAQ) — отметь places, где нужны уточнения от меня, не выдумывай.

## Что подготовить (11 документов)

### Промпты (канал foxray-sales)
- `system-foxray` — SYSTEM. Кто агент (sales-ассистент FoxRay для ортодонтов, подписка), тон, рамки, что НЕ делает (оплату/заказ не проводит, не обещает вне базы знаний).
- `qualify-foxray` — QUALIFICATION. Какие вопросы задать: размер практики, сколько пациентов ведёт, что важно (брендирование, скорость расчётов, командная работа), пробовал ли аналоги.
- `sales-foxray` — SALES_BEHAVIOR. Как подобрать тариф под ответы (Бесплатный для старта / Про для практики / Макс «скоро»), как мягко довести до старта или покупки, без давления.
- `handoff-foxray` — OPERATOR_HANDOFF. Когда передавать оператору: просьба о человеке, индивидуальные условия/скидка, жалоба/спор, вопрос вне базы знаний.

### Знания (FoxRay)
- `foxray-overview` — OVERVIEW / MANDATORY. Что такое FoxRay, какую задачу ортодонта решает, в чём ценность.
- `foxray-audience` — AUDIENCE / RETRIEVAL. Для кого (типы практик, роли в клинике), кому особенно полезен.
- `foxray-tariffs` — COMMERCIAL / MANDATORY. Подробно Бесплатный/Про/Макс: что входит, цены, мес/год, чем отличаются, кому какой.
- `foxray-technical` — TECHNICAL / RETRIEVAL. Возможности и как устроено: расчёты, PDF/отчёты, брендирование, доступ, интеграции (если есть — иначе пометь, что уточнить).
- `foxray-faq` — FAQ / RETRIEVAL. Частые вопросы и короткие ответы.
- `foxray-objections` — OBJECTIONS / RETRIEVAL. Типичные возражения (дорого, привык к другому, нет времени внедрять) и корректные ответы.
- `foxray-limitations` — LIMITATIONS / RETRIEVAL. Чего FoxRay не делает; ограничения тарифов (например, лимит пациентов на Бесплатном).

## Формат ответа (строго)

Верни **один Markdown-файл**. Каждый документ — секция: строка-разделитель с кодом,
затем с новой строки содержимое:

```
=== code ===
<содержимое простым текстом>
```

Правила:
- `code` — ровно из списка выше (11 штук), ничего не добавлять, не переименовывать, не пропускать.
- Между секциями — пустая строка; содержимое может быть в несколько абзацев.
- Внутри — простой текст, без markdown-разметки.
- Никаких метаданных (категории/scope уже у меня) — только `=== code ===` + текст.

Пример:

```
=== foxray-overview ===
FoxRay — это сервис для ортодонтов, который ...

=== foxray-tariffs ===
У FoxRay три тарифа. Бесплатный — до 3 пациентов ...
Про — 4 900 ₽ в месяц или 47 040 ₽ в год ...
Макс — всё из Про плюс AI-расстановка точек, скоро ...
```

Всего секций: **11** (4 промпта + 7 знаний).
