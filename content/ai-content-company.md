# Edevs AI — контент агента: компания (главный сайт)

Задание на контент для агента канала **edevs** (главный сайт компании, без привязки к продукту).
Заполненный результат (по разделу «Формат ответа») вернёшь — я загружу и протестирую.

## Роль канала edevs
Агент главного сайта консультирует по компании в целом, кратко рассказывает об обоих продуктах
и помогает посетителю понять, что ему подходит (FoxRay или FirePage), либо передаёт оператору.
Глубокие знания по продуктам у агента есть отдельно (контент FoxRay/FirePage уже подготовлен) —
здесь нужны только общие документы о компании и общая роль агента.

## Как устроено (коротко)
- **Промпты**: `SYSTEM`, `QUALIFICATION`, `SALES_BEHAVIOR`, `OPERATOR_HANDOFF`.
- **Знания** (scope GLOBAL — про компанию): категории `OVERVIEW`, `FAQ`; `inclusion`: `MANDATORY`/`RETRIEVAL`.

**Стиль**: простой текст для мессенджера, по-русски, без markdown, кратко. Только реальные факты.

## Зафиксированные факты (используй, не противоречь)
- Компания **Edevs** делает два продукта:
  - **FoxRay** — сервис для ортодонтов (онлайн цефалометрический ТРГ-анализ), по подписке (Бесплатный/Про/Макс).
  - **FirePage** — готовые нишевые сайты на своей CMS, разовая лицензия (один сайт — одна лицензия).
- Оплата/выдача — в бэкенде продуктов. Агент оплату не проводит.

> Чего не хватает о компании (история, контакты, гарантии, оферта) — отметь «уточнить», не выдумывай.

## Что подготовить (7 документов)

### Промпты (канал edevs)
- `system-edevs` — SYSTEM. Кто агент (ассистент главного сайта Edevs), тон, рамки; кратко знает оба продукта; помогает сориентироваться и направить.
- `qualify-edevs` — QUALIFICATION. Вопросы, чтобы понять, кто пришёл (ортодонт? нужен сайт для бизнеса?) и в какой продукт направить.
- `sales-edevs` — SALES_BEHAVIOR. Как мягко подвести к нужному продукту и следующему шагу (рассказать про FoxRay или FirePage), без давления.
- `handoff-edevs` — OPERATOR_HANDOFF. Когда передавать оператору (просьба о человеке, партнёрство/иные вопросы, жалоба, вне базы знаний).

### Знания (GLOBAL — про компанию)
- `company-overview` — OVERVIEW / MANDATORY. О компании Edevs: чем занимается, чем полезна, ценность.
- `company-products` — OVERVIEW / MANDATORY. Кратко оба продукта (1–2 абзаца на каждый): что это, кому подходит, модель оплаты — чтобы агент мог сориентировать и направить.
- `company-faq` — FAQ / RETRIEVAL. Частые общие вопросы (как купить, поддержка, оплата, безопасность данных, чем продукты отличаются).

## Формат ответа (строго)

Верни **один Markdown-файл**. Каждый документ — секция:

```
=== code ===
<содержимое простым текстом>
```

Правила:
- `code` — ровно из списка выше (7 штук), ничего не добавлять, не переименовывать, не пропускать.
- Между секциями — пустая строка; содержимое может быть в несколько абзацев.
- Только `=== code ===` + текст; метаданные не нужны.

Всего секций: **7** (4 промпта + 3 знания).
