# Вектор — руководство по развёртыванию коробочной лицензии

## Системные требования

- **ОС:** Linux (Ubuntu 22.04 LTS / РЕД ОС 7.3)
- **Процессор:** 4 ядра
- **ОЗУ:** 8 ГБ
- **Диск:** 80 ГБ SSD
- **Сеть:** доступ к контроллерам оборудования по OPC UA (4840) и Modbus TCP (502)

## Порядок установки

1. Разверните дистрибутив из архива `vektor-server-<version>.tar.gz`.
2. Укажите лицензионный ключ в `/opt/vektor/etc/license.conf`.
3. Запустите сервис: `systemctl start vektor-server`.
4. Откройте веб-консоль на `https://<сервер>:8443` и задайте пароль администратора.

## Подключение контроллеров

- OPC UA: добавьте endpoint в разделе «Источники → OPC UA».
- Modbus TCP: укажите IP и список регистров в «Источники → Modbus».

## Проверка

После подключения зайдите в «Живые данные» — метрики должны обновляться в течение секунды.
Если данных нет, проверьте сетевую связность и брандмауэр.
