# Голосовые сообщения демо

Сюда кладутся аудиофайлы, на которые ссылается `data/conversations.json`
(`messages[].voice.file`). Речь должна быть человеческой и совпадать с текстом
`transcript` соответствующего сообщения — расшифровка показывается рядом с плеером.

| Файл | Кто говорит | Длительность | Текст |
| --- | --- | --- | --- |
| `maria-hurry.ogg` | клиентка, Мария | ~14 с | «Анна, спасибо! Если получится отправить завтра, будет идеально — в субботу приезжают гости, хочу успеть повесить.» |
| `olga-color.ogg` | клиентка, Ольга | ~9 с | любой текст: сообщение показывается нерасшифрованным (кнопка «Расшифровать») |
| `dmitry-samples.ogg` | сотрудник, Дмитрий | ~18 с | «Дарья, добрый день, это Дмитрий из ателье. Отправлю вам три образца блэкаута: графит, дымчатый и тёмно-серый. Напишите адрес с индексом, уйдут завтра почтой.» |

Формат — OGG/Opus (как в Telegram и MAX), моно, 16–48 кГц. Лицензия — совместимая
с открытой публикацией (CC0/CC BY или собственная запись). Если файла нет, сид
пропускает сообщение с предупреждением в логе — остальные данные ставятся.
