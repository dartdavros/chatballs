# Quoting for made-to-measure curtains

## The formula

**Price = fabric + making + hardware**

| Component | How we count it |
| --- | --- |
| Fabric | metres × price per metre (see the fabric catalogue) |
| Making, curtains | £18 per linear metre of finished width |
| Making, voile | £14 per linear metre of finished width |
| Eyelets | £3.50 each (18 cm apart) |
| Heading tape | £4.80 per metre |

## Fullness ratio

- Heavy curtains — 1.5
- Linen, canvas — 1.8
- Voile, sheers — 2.0–2.5

Fabric width = track width × ratio. Fabric drop = finished drop + 15 cm for the hem.

## Worked example

A 3 m track, 2.6 m drop, Nord blackout at £59/m, two curtains.

- Fabric: 3 × 1.5 = 4.5 m × £59 = £265.50
- Making: 4.5 × £18 = £81
- Tape: 4.5 × £4.80 = £21.60
- **Total: £368.10**

Minimum order — £120. Measuring within London is free on orders over £600.
