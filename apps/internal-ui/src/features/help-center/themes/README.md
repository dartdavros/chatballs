# Визуальные темы порталов

Подробная инструкция: [RUNBOOK-CHATBALLS-0003](../../../../../../../../docs/runbooks/RUNBOOK-CHATBALLS-0003-Portal-Theme-Development.md)
— справочник токенов, тёмная схема, проверки и чек-лист. Ниже — памятка.

Тема — это папка в этом каталоге. Чтобы добавить свою, не нужно править
бэкенд, реестр или список где-либо ещё: тема подхватывается по факту наличия
папки (`import.meta.glob` в [registry.ts](registry.ts)).

## Как сделать тему

1. Скопируйте `classic/` в `themes/<ваш-id>/`.
   Идентификатор — строчные латинские буквы, цифры и дефис (`aurora-dark`).
   **Имя папки обязано совпадать с `id` в манифесте** — это проверяет тест.
2. Заполните `manifest.ts`: `name` и `description` видны владельцу портала в
   настройках, `schemes` перечисляет поддерживаемые цветовые схемы, `preview` —
   три цвета для превью.
3. Переопределите нужные токены в `theme.css`.
4. Выберите тему в карточке портала: `Настройки → Оформление`.

```
themes/
  contract.css        # значения токенов по умолчанию (базовый вид)
  types.ts            # тип манифеста
  registry.ts         # автообнаружение тем
  usePortalTheme.ts   # применение темы к документу
  classic/
    manifest.ts
    theme.css
```

## Правила

- **Скоуп.** Все правила `theme.css` пишутся под селектором
  `html[data-portal-theme="<id>"]`. Глобальные правила и правки чужих файлов
  запрещены — тест `registry.test.ts` это проверяет. `@keyframes` называются с
  префиксом id темы (`aurora-pulse`).
- **Только объявленные токены.** В `theme.css` допустимы `--help-*` из
  [contract.css](contract.css); неизвестные токены тест не пропустит. Если
  нужного рычага нет — добавьте его в контракт и в вёрстку Help Center одним
  изменением, а не заводите частный токен в теме.
- **Тёмная схема.** Если тема заявляет `"dark"`, значения для неё пишутся под
  `html[data-portal-theme="<id>"][data-theme="dark"]`. Схема выбирается в
  настройках портала (`Светлая / Тёмная / Как в системе`); темам, заявившим
  только `"light"`, тёмный вариант в настройках не предлагается.
- **Никакого JS.** Тема — это токены и, при необходимости, скоупнутый CSS.
  Компонентные слоты пока не поддержаны: если тема требует другой разметки,
  это отдельное решение владельца продукта, а не обход через тему.
- **Без внешних ресурсов.** Шрифты и картинки — из репозитория; загрузка со
  сторонних CDN на публичной странице портала не допускается.

## Токены

Полный список с комментариями — в [contract.css](contract.css). Кратко:

| Группа       | Токены                                                                 |
| ------------ | ---------------------------------------------------------------------- |
| Типографика  | `--help-font-body`, `--help-font-heading`, `--help-font-mono`, `--help-heading-weight` |
| Поверхности  | `--help-bg`, `--help-surface`, `--help-surface-soft`, `--help-surface-raised`, `--help-surface-strong` |
| Текст        | `--help-ink`, `--help-text`, `--help-text-muted`, `--help-text-subtle`  |
| Линии        | `--help-line`, `--help-line-soft`                                       |
| Акцент       | `--help-accent`, `--help-accent-hover`, `--help-accent-ink`             |
| Код          | `--help-code-bg`, `--help-code-ink`, `--help-code-inline-bg`            |
| Скругления   | `--help-radius-xs/sm/md/lg/xl/pill`                                     |
| Тень         | `--help-shadow-panel`                                                   |

## Пример

```css
html[data-portal-theme="aurora"] {
  --help-bg: #f7f8fc;
  --help-accent: #4c5fd7;
  --help-accent-ink: #ffffff;
  --help-radius-md: 18px;
}

html[data-portal-theme="aurora"][data-theme="dark"] {
  --help-bg: #12131a;
  --help-surface: #191b23;
}
```
