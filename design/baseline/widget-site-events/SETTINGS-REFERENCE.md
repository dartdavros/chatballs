## Уточнение после замечаний к eccd6aa8

- Подпись ограничения больше не располагается над одним из контролов строки: она находится слева от поля. Подписи имени и типа скрыты визуально без остаточного отступа, доступные имена сохранены. Колонка ограничений вмещает подписи и значения обеих числовых границ. Центры полей, селекта, переключателя и многоточия совпадают для text/number/boolean в ru/en, light/dark, 320/768/1440.
- В прежнем меню уже был antd Dropdown, но его item содержал сырой текст. Этого недостаточно для `shared/menu.css`, где размеры, отступы, цвет действия и иконка рассчитаны на вложенный button. Теперь item повторяет структуру удаления из `integrations/rows.tsx` / RowActions: button.warning, Icon trash 15, закрытие меню перед действием. Используются существующие Dropdown, Icon и общие стили; отдельного оформления меню нет.
- Проверено именно открытое меню: ширина 220, пункт 33, иконка, закрытие по Esc/клику вне, удаление. Снимки: [числовые поля](verification/schema-number-ru-light-1440.png), [меню светлое](verification/schema-menu-ru-light.png), [меню тёмное](verification/schema-menu-en-dark.png). Подробные измерения: [task-local-settings-schema.json](verification/task-local-settings-schema.json).

Индивидуальный CSS ограничен колонками таблицы данных события и резервом высоты подсказки каталога. Это новые данные требования R-2, а не новый стандарт полей, кнопок, ссылок, карточек или алертов. Готовность/загрузка/пустота/ошибка не меняют высоту каталога; размеры проверены на 320/768/1440 в обеих темах и языках.

Собственный раскрывающийся блок справки удалён из продуктовой формы. Объяснение TTL/reload/повторов сохранено в README и кадрах посетителя V12–V16; продуктовая справка остаётся объёмом реализации спецификации.
