## Что проверено

| Область | Фактическая проверка |
|---|---|
| Настройка | Новое правило выключено; отсутствие сценария и пустое поле блокируют сохранение; выбор, добавление/удаление поля, общий antd Dropdown, retry каталога; изменение сбрасывает сохранённый статус; числовые границы в одной ячейке, у boolean нет лишних ограничений |
| Каталог | Единственная ссылка на существующий общий editor.dc.html; высота области готовности/загрузки/пустоты/ошибки одинакова на каждой ширине |
| Приглашение | Панель закрыта; следующее событие не заменяет текст; нет audio, unread или bump; Esc закрывает и возвращает фокус launcher |
| Согласие | Оригинальные экран/форма; обязательное имя блокирует начало; показана редакция 2 при старом согласии; актуальное согласие не переспрашивается и панель не открывается сама |
| Первый ответ | Нет клиентской реплики; один ответ AI. Отправка обычного текста и перехват сотрудником подавляют поздний проактивный результат |
| TTL/reload | Иллюстрации исчезновения, подавления повтора и позднего согласия не создают ответ; V17 не открывает завершённый диалог |
| Ошибки | Нет ложного пузыря ответа, технического кода; ввод доступен при ошибке и недоступности AI |
| Геометрия | Нет горизонтального переполнения страницы и формы; таблица на узкой ширине имеет собственную горизонтальную прокрутку по образцу SiteFields, включая доступ клавиатурой. Launcher 56×56, отступы 24 внутри границы кадра; desktop panel 440, expanded 820; mobile fullscreen, launcher скрыт |
| Доступность | Клавиатурный порядок настроек, Enter для принятия, Esc для закрытия, восстановление фокуса, обязательное поле, CSS-масштаб 200% в en/dark |
| Локализация | Совпадение ключей, проверка отсутствия кириллицы во всех en кадрах; системные строки берутся из исходных компонентов |
| Темы | Светлая и тёмная тема рабочего места, прежняя светлая палитра самого виджета |

Здесь проверены **результаты и переходы дизайн-документа**, а не реальный протокол/хранилище/AI. Настоящий TTL, сохранение отметки при reload, consent gate, дедупликация и гонки сервера должны проверяться при реализации.
