# Левое меню Chatballs

Основа — интерактивное превью `sidebar-navigation.dc.html`, утверждённое владельцем в этой задаче перед реализацией. Стили, высоты пунктов, темы и поведение мобильной панели сохраняют систему существующего интерфейса.

## Утверждённая структура

Группы разделены горизонтальными линиями, без видимых заголовков:

1. Чат · Контакты · Статистика.
2. Агенты · Сценарии · AI-провайдеры · MCP и HTTP.
3. База знаний · Порталы.
4. Виджеты · Мессенджеры · Почта · Интеграции.
5. Сотрудники · Настройки.

Помощь закреплена ниже прокручиваемого меню, перед профилем.

## Иконки

- Сценарии — Lucide Workflow.
- Виджеты — Lucide MessageCircle, по отдельному указанию владельца.
- Мессенджеры — Lucide MessagesSquare.
- Настройки → Платформа — Lucide ServerCog: дополнительное указание владельца заменить повторяющуюся иконку по контексту. Глобус сохранён у Порталов.
- Остальные иконки — существующие. Новых зависимостей нет.

## Поведение

AI-провайдеры, сценарии и подключения открываются самостоятельными разделами. Провайдеры включают модели и речевые сервисы; мессенджеры — Telegram, MAX и ВКонтакте, включая ботов уведомлений. Почта отделена от мессенджеров. MCP и HTTP сохраняют оба типа инструментов. Интеграции содержат внешние бизнес-сервисы.

Внутреннее содержимое перенесённых разделов использует существующие таблицы, формы, карточки и стили Settings без вложенного меню настроек. Старые адреса поддерживаются роутером; тип старой карточки подключения определяется по API. Изменение навигации не расширяет права сотрудников.
