# Т167 — запуск, подтверждения и журнал: перечень кадров

Основа — «Сервисы», «Сценарии», меню настроек 1b. Ширина (1440/1024), тема и акцент — в панели Tweaks каждого файла.

## Маршрут просмотра (≈10 минут)
1. **Агент · действия** → «Обычное состояние»: три режима у каждого действия. «Запись самостоятельно» — предупреждение без обязательного подтверждения. «Подключение недоступно», «Нечего разрешать».
2. **Запуск из диалога** → группа «Запуск»: L1 меню «Действия» → L2 параметры → L3 пустое обязательное поле → L4 операция только чтения → L5 нет действий.
3. Группа «Выполнение и сбои»: R1 выполняется → R2 готово (ссылка в карточке) → R3 частично → R4 неизвестный результат (без «Повторить») → R5 ожидание → R6 нет доступа.
4. Группа «ИИ»: C1 запрос подтверждения → C2 подтверждено → C3 отклонено / истёк срок / нужно новое подтверждение → C4 уже обработано другим / нет права → A1 перехват диалога у ИИ → T1/T2 проверочный чат: проверка и настоящее выполнение.
5. Группа «Мобильные»: M1 подтверждение, M2 запуск, M3 выполнение.
6. **Журнал запусков**: список, фильтры, вкладки состояний, поиск → загрузка / пусто / ошибка / нет прав.
7. Состояния запуска: выполняется, ожидает, успешно, частично, неизвестно, отменён (результат после отмены), авто-повтор, нет доступа, несовместимая версия, ветви и перебор, данные удалены.
8. Восстановление: «Продолжить» (только незавершённое), «Новый запуск» (отдельный номер, предупреждение о дублях), «Компенсация» (отдельное действие, не откат), «Отмена», «Проверка → найден», «Изменился при просмотре».

## Правила, закрытые во втором проходе
- **Доступ к запуску.** Страница запуска открыта всем, кто видит диалог (участники, запустивший, подтверждающий), и администраторам. Журнал всей организации — только администраторам.
- **Значения из шагов.** Источник «Результат шага» — это пара «шаг + поле» (номер, ссылка, сумма…). Внутри перебора есть источник «Текущий элемент» с выбором поля.
- **Составные шаги.** У «Для каждого», «Одновременно», «При ошибке» есть свои вложенные списки шагов с кнопкой «Добавить шаг сюда». У «Одновременно» есть ещё «Добавить ветку».
- **Время.** И расписание, и ожидание «до…» задаются полем времени в часовом поясе организации.
- **Ключ внешнего запуска.** Создаётся при сохранении и показывается целиком один раз. Потом виден только замаскированным, есть «Создать новый ключ».
- **Обмен данными.** Переключатель появляется только после настройки. Обмен работает лишь для записей, уже связанных сценариями. У каждой пары своё соответствие полей, для «Диалог ↔ Лид» есть ещё таблица «статус → стадия». При правиле «Ничего не менять» расхождение появляется в журнале как «Нужно решение»: для каждого поля администратор выбирает одно из двух значений.
- **Связанные записи.** У каждой записи есть меню: открыть, связать с другой, снять связь. Замена не меняет данные во внешнем сервисе, уже идущие запуски дорабатывают со старой связью.
- **При ошибке.** Внутри «Если ошибка» есть источник «Ошибка»: причина, название и номер шага, сервис, номер запуска.
- **Вложенный сценарий.** Входные параметры (его «Спросить при запуске») заполняет вызывающий сценарий: значение, диалог, результат шага, текущий элемент или свой вопрос при запуске. Незаполненный обязательный параметр блокирует включение.
- **Хранение.** Сроки меняются в «Настройки → Организация». Сокращение срока требует подтверждения, удаление происходит через 24 часа.

## Новые переиспользуемые элементы
- Карточка запуска в ленте (шаги, состояние, номер, «Подробнее»).
- Карточка подтверждения ИИ (параметры, срок, изменённые значения выделены).
- Панель запуска (план «Что произойдёт», поля с источником значения).
- Дерево шагов журнала с вложенностью, перебором и ветвями.
- Переключатель режима действия агента (3 значения).
