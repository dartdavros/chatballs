# Выбор действия в диалоге

Макет `action-picker.dc.html` утверждён владельцем 11 ноября 2026 года
в текущем обсуждении изменений Chatballs. Он заменяет плоский список выбора
действия из прежнего baseline «Запуск из диалога».

Утверждённое поведение:

- Модалка с поиском и отдельной прокруткой вложенного списка.
- Подключения сервисов различимы по названию; категории операций заданы адаптером.
- Пользовательские сценарии располагаются в собственных категориях.
- Поиск учитывает слова из названия, сервиса, категории и подключения.
- Во время поиска раскрываются совпавшие ветви; очистка восстанавливает раскрытие.
- Только активные действия, доступные текущему сотруднику в текущем диалоге.
- Счётчики вычисляются после проверки доступности и поиска; пустых групп нет.
- Выбор открывает существующую форму параметров. Запуск требует отдельного действия.
- Дополнение владельца при утверждении: во всех полях поиска показывается `/`
  по образцу поиска в чате. Подсказка скрывается при вводе запроса.

Имена, подключения и параметры в макете — демонстрационные данные.
В приложении используется серверный каталог и существующий `ManualLaunch`.
Параметры и результат в макете служат только демонстрацией перехода после выбора.

HTML, CSS и JavaScript разделены для соблюдения принятого размера модулей.
Иконки берутся из установленного в проекте Lucide после `npm ci`.
