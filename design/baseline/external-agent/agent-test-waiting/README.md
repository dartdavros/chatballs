# S06 — ожидание внешнего ответа в проверочной панели

Единственный кадр **S06-r1** — обычное ожидание после отправки одной примерной реплики. Лично принят владельцем 15.11.2026 для версии `S06-26b466b218854dd8`, хеши 221 исходника/ресурса — `generated/sources.json`. Решение зафиксировано в `OWNER-ACCEPTANCE.md`.

Открыть `waiting.dc.html` напрямую в браузере по умолчанию. Это статический дизайн состояния, не выполненный тест. Примерная реплика — содержимое документа. Реального запроса, подтверждения принятия сервисом, его действий или доставки не было. API, ответы-заглушки, HTTP-серверы, seed-данные и внешние сервисы не используются.

## Принятое состояние

- Сохраняются текущая правая панель 420 px и принятый контекст S05. На фоне остаётся выбранное внешнее исполнение, AI остановлен. Открытая проверка не запускает автономные ответы.
- В ленте одна примерная клиентская реплика и отдельная строка «Ожидаем ответ внешнего агента» с общим индикатором. Ответ ещё не получен; реплика не имеет статуса принятия/доставки/прочтения. Ответы, ошибки, действия, инструменты и сведения о внутренней обработке не изображены.
- Композер очищен, ввод и отправка заблокированы; у отправки `aria-busy`. Тестовые данные неизменяемы, разрешённые поля клиента остаются пустыми. Дополнительные данные не подставляются.
- **Предлагаемое отличие от текущей встроенной панели:** «Начать заново» недоступно во время ожидания. Локальный abort не гарантирует остановки зарегистрированной внешней работы; нельзя изображать перезапуск как безопасный повтор. Закрытие и Esc остаются закрытием, без обещания остановки или отката внешних действий. В статическом кадре они не меняют состояние.
- Предупреждение о настоящем выполнении сохраняется. Предпросмотр без действий, принудительный повтор, таймер, проценты и кнопка остановки не добавлены.
- Готовые возможность, подключение, привязка и политика агента — предпосылки кадра. Доступность внешнего сервиса и допустимость конкретного диалога/согласия этим макетом не подтверждаются.

Загрузка не меняет геометрию панели: шапка, предупреждение, данные, прокручиваемая лента и композер сохраняют текущую компоновку. Для индикатора выделена строка минимальной высоты 88 px с учётом двух строк заголовка, пояснения и отступов. Не изображается длительное ожидание или истечение срока — это отдельные состояния для следующих решений владельца.

## Проверка и ограничения

`node design/baseline/external-agent/agent-test-waiting/check-browser.mjs` проверяет только S06 через `file://` в установленном Chrome. Протокол и снимки — `verification/`, хеши исходников — `generated/sources.json`.

Итог: **PASS** для версии выше. Проверены ru/en × светлая/тёмная тема × 1440/1024/390/320 px, два дополнительных акцента, CSS-масштаб 200%, общий анимированный индикатор, постоянная геометрия областей, одна клиентская реплика без ответа, блокировки и статические действия. Браузерных ошибок и HTTP(S)-запросов — 0. Все хеши принятых S01/S02/S03/S04/S05 (200/204/208/212/272 исходника) совпадают. Максимальный authored-файл — 198 строк с учётом завершающего перевода строки, TSX-компоненты меньше 180 строк.

Исходное ограничение `min-width:1024px` сохранено. На 320/390 px панель осматривается горизонтальной прокруткой; новая мобильная компоновка не вводится. Проверка дизайна не подтверждает реальную обработку, отмену или доставку.
