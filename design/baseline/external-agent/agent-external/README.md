# S04 — карточка агента с выбранным внешним исполнением

Единственный кадр **S04-r1** лично принят владельцем 15.11.2026 для версии `S04-1d495df459254c46`. Границы и решение зафиксированы в `OWNER-ACCEPTANCE.md`. Проверочная панель готовится отдельно как S05; исходники принятого S04 сохраняются.

Открыть `agent.dc.html` напрямую в браузере по умолчанию. Это статический дизайн, не запущенное приложение. API, исполнение агента, сохранение, проверочный диалог и доставка не выполняются. Подключение, клиентский канал и настройки — примерное содержимое документа, без секретов и сетевых заглушек.

## Предлагаемое состояние

- Возможность уже включена в принятых настройках. В существующей карточке выбран внешний способ и подготовленное исполнение «Сервис поддержки» своей организации. Обычные CRM-интеграции, AI-провайдеры и MCP/HTTP-инструменты не представлены исполнителями.
- Для кадра предполагаются подготовленная в настройках привязка этого агента и параметры передачи. Согласие клиента, полномочия и управление конкретным диалогом проверяются при работе отдельно; кадр не подтверждает их наличие во всех диалогах.
- Существующий статус `DRAFT` отображается текущим компонентом как «Без AI». Выбор исполнения не запускает ответы; кнопка запуска и проверочная панель в статическом документе ничего не выполняют. «Подключение готово» относится только к подготовленному подключению.
- Встроенные инструкции, текстовая модель, знания, навыки, действия и инструменты скрыты с пояснением о сохранении значений. Это предложение представления для личной приёмки. Они не изображены настройками внешнего ответа.
- Язык ответов вынесен из встроенных инструкций. Он передаётся как настройка, без обещания редактирования промпта внешнего сервиса.
- Речь самостоятельна: распознавание явно использует SpeechKit, наследования «Как у ответов» нет. Chatballs передаёт распознанный текст; озвучивание независимо выключено.
- Сохраняются текущие шапка, имя, активность, группа, помощь сотрудникам и клиентские подключения. Встроенный провайдер сохранён для независимой помощи сотруднику; общий запрет внешних ответов при отсутствии LLM не монтируется.
- Адрес, ключи, внешние идентификаторы, проверка подключения, сроки, разрешения на данные и шаблоны не дублируются в карточке. Переход в те же настройки показан штатной ссылкой; другой кадр не открывается.

## Источники визуального решения

Старые макеты не использовались. Основа — текущий код `AgentDetailPage.tsx`, его сетка, стили и компоненты. `AgentHeader`, `AssignmentCard`, `ConnectionsCard` и `SynthesisSettings` импортируются напрямую без загрузчиков данных страницы. Новый выбор использует действующие `SelectField`, antd-меню, `StatusPill`, `.link`, существующую иконку перехода. Язык повторяет текущий сегмент-контрол `InstructionsCard`; речь — текущие поля `SpeechSettings` с явным STT. Оболочка следует `Sidebar.tsx` и использует настоящие компоненты навигации без realtime-хуков.

`IndependentAssistanceCard` сохраняет разметку и стили текущего `AssistanceCard`, без сохранения/ошибок вне данного кадра. Единственная предложенная текстовая корректировка существующего блока: нейтральная ссылка на «кнопку AI в шапке», поскольку текущий код всегда пишет «Остановить AI», даже когда в шапке показано «Запустить AI». Продуктовый компонент и словари не изменялись.

Новые ru/en-тексты — предложение в локальном `copy.ts`; продуктовые словари не менялись. Разделение на модель, карточки, оболочку и canvas сохраняется; максимальный authored-файл — 162 строки с учётом завершающего перевода строки. `support.js` используется только как загрузчик `.dc.html`. Общие presentation-only данные оболочки и CSS canvas переиспользуются без изменения принятых файлов S01.

## Проверка и ограничения

`node design/baseline/external-agent/agent-external/build.mjs` собирает только статические дизайн-ресурсы и проверяет ru/en, размеры файлов и SHA256 исходников. Сборка приложения не запускалась.

`node design/baseline/external-agent/agent-external/check-browser.mjs` проверяет единственный S04 в установленном Chrome через `file://`: ru/en × светлая/тёмная тема × 1440/1024/390/320 px, два дополнительных акцента, CSS-масштаб 200%, неизменность статических действий и самостоятельное меню STT. Результат — PASS, 0 браузерных ошибок и HTTP(S)-запросов. Снимки и протокол — `verification/`; версия и хеши 212 исходников — `generated/sources.json`.

Незавершённая ранее проверка меню исправлена в проверочном скрипте: он различает меню шапки и поля и дожидается закрытия анимации перед следующим действием. Сам экран в этом проходе не менялся. Итоговый протокол содержит явный `status: PASS` для версии выше.

Текущее ограничение приложения `min-width:1024px` сохранено. На 320/390 px используется горизонтальная прокрутка, без новой мобильной компоновки. Проверка этих ширин не подтверждает готовность мобильного интерфейса. На десктопных ширинах случайного переполнения карточек нет.

Принятые версии S01/S02/S03 и все их 200/204/208 хешей совпадают. Продуктовый код, backend, аккаунты и настройки не менялись. Проверка дизайна не подтверждает работу интеграции.
