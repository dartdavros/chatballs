# S05 — проверочная панель агента с внешним исполнением

Единственный кадр **S05-r1** — начальное состояние открытой панели до первой отправки. Лично принят владельцем 15.11.2026 для версии `S05-6dcaa8de64ce4db2`, хеши 272 исходников/ресурсов — `generated/sources.json`. Решение зафиксировано в `OWNER-ACCEPTANCE.md`; ожидание после отправки готовится отдельно как S06.

Открыть `test.dc.html` напрямую в браузере по умолчанию. Это статический дизайн. API, реальные запросы, запуск внешних действий, сохранение и доставка не выполняются. Нет mock API, HTTP-сервера, seed-данных или ответов-заглушек. Пустая лента не изображает выполненный тест.

## Что предлагается

- На фоне остаётся принятая карточка с выбранным внешним исполнением. Кнопка «Проверить агента» активна как у открытой панели; AI остановлен, его автоматический запуск не подразумевается.
- Возможность включена, подключение, привязка и параметры агента предполагаются заранее подготовленными в тех же настройках. Этот кадр не предоставляет обхода выключенной возможности, отсутствующих разрешений или согласия.
- Панель сохраняет текущие 420 px, правое наложение, заголовок, действия перезапуска/закрытия, область данных, ленту и композер. Диалог и поле сообщения пустые. Отправка неактивна из-за пустого сообщения, а не из-за отсутствия дополнительных полей.
- Показаны внешний сервис и «Настоящее выполнение». Переключателя предварительного просмотра нет: безопасная имитация внешнего исполнения контрактом не предусмотрена. Предупреждение сообщает о передаче текста и возможности реальных действий сервиса.
- Списки разрешённых полей клиента в этом кадре пусты. Вместо имени/email/телефона и своих полей показано пояснение об отсутствии разрешённой передачи. Это не редактор разрешений; их настройка остаётся в настройках внешнего исполнения.
- Убраны неподтверждённые обещания текущего встроенного теста: «никуда не сохраняются», встроенное маскирование, отсутствие записей в контактах/статистике. Нет предупреждения о модели/инструментах встроенного Chatballs для внешнего запроса.
- Ключи, адрес сервиса, внешний ID, сроки, разрешения и шаблоны в панели не дублируются. Ответ, ожидание, ошибки и остановка обработки не смешиваются с начальным состоянием; следующие кадры требуют отдельного решения владельца.

Все действия статические. Перезапуск переводит фокус в пустой ввод, закрытие и Esc сохраняют единственный предъявляемый кадр; это не проверка закрытия панели работающего приложения. Отправка и Enter не создают запрос, сообщение или ответ.

## Источники текущего кода

| Элемент | Источник |
|---|---|
| Панель, заголовок, фокус, Esc и композер | `apps/internal-ui/src/features/agents/test-chat/AgentTestPanel.tsx` и `styles.css` |
| Пустая лента | Напрямую импортированный `TestChatFeed`, без тестового hook/API |
| Предупреждение реального выполнения | Существующие `.agent-action-test-mode.is-warning` из `features/agents/actions/actions.css`; новые ru/en-подписи предложены в `copy.ts` |
| Область данных без разрешённых полей | Разметка и стили текущего `TestClientData`, без безусловных полей контакта и обещаний встроенной обработки |
| Фоновая карточка и оболочка | Текущая композиция `AgentDetailPage`, реальные общие компоненты и неизменённые принятые подвиды S04 |
| Темы, акценты, формы, меню, иконки | Текущие стили и компоненты приложения, `packages/ui`, `shared/appearance` |

Старые макеты не использовались как визуальный источник. Новые локальные тексты — предложение на личную приёмку; продуктовые файлы и словари не изменялись. Убрано только неприменимое к внешнему исполнению содержимое существующей панели; новый визуальный стандарт не вводился.
