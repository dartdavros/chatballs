# S03 — подключение настроено и готово

Экран **S03-r1, Настройки → Обслуживание → Внешнее исполнение**, лично принят владельцем 15.11.2026 для версии `S03-2122cd3c3c071bf6`. Решение — `OWNER-ACCEPTANCE.md`. Внешняя возможность включена, подключение сохранено, проверка доступности и совместимости показана успешной. Готовность относится к подключению; конкретный агент дополнительно требует привязки, разрешений и допустимого состояния диалога/согласия клиента. Этот документ открывает только принятый S03; карточка агента готовится отдельно как S04.

Открыть `settings.dc.html` напрямую в браузере по умолчанию. Это статический дизайн, не работающая интеграция. `https://agent.example`, название и результат проверки — явно примерное содержимое. Никакие endpoint, credentials или ответы API не запрашиваются и не подменяются. Реальная проверка сервиса, тестовый диалог и доставка сообщений не выполнялись.

## Что предъявляется на утверждение

- Сохранены лично принятые раздел, последнее место пункта в группе «Обслуживание», иконка сервера, ширина и оформление карточек.
- Подключение имеет название и примерный HTTPS-адрес. Статус — «Подключение готово», без утверждения, что все агенты уже отвечают.
- Два направления доступа остаются раздельными. Оба ключа замаскированы; значения `input.value` пустые, точки — только фиксированный placeholder. Реальных, временных или фиктивно сгенерированных токенов в документе нет.
- Для исходящего ключа показано действие замены сохранённого реквизита. Для входящего — замена и отзыв с объяснением прекращения доступа по прежнему ключу. Ключ не раскрывается и не копируется; действия в макете не выполняются.
- Проверка возможностей показана штатным здоровым статусом «Совместим» в выделенной строке. Подпись поясняет доступность сервиса, поддерживаемые форматы и зависимость от канала/разрешённых шаблонов. Проверка не означает ответ агента или доставку сообщения.
- Сохранение недоступно, поскольку показанная конфигурация не изменена. Повторная проверка, замена/отзыв и переключение не переводят на другие непринятые состояния.

Настройка привязок и отдельных политик остаётся в этом же разделе настроек и рассматривается последующими кадрами. Параметры 120 секунд/24 часа не подставляются как якобы существующие сохранённые значения API. Текущий кадр не выдаётся за готовность всей интеграции или приёмку всего baseline.

## Проверка и версия

`node design/baseline/external-agent/settings-ready/build.mjs` собирает только ресурсы дизайна, проверяет тексты и размеры файлов. Сборка приложения не запускается.

`node design/baseline/external-agent/settings-ready/check-browser.mjs` проверяет один S03 через native file URL в установленном Chrome: темы/языки/ширины, маски без секретных значений, готовность подключения и отдельные направления, статические действия, отсутствие HTTP(S)/ошибок, хеши принятых S01/S02. Масштаб 200% — CSS-масштаб просмотра, не утверждение о нативном zoom браузера.

Точная версия — `generated/sources.json`, протокол и снимки — `verification/`, решение владельца — `OWNER-ACCEPTANCE.md`. Браузерная проверка макета не является проверкой сервиса или созданием/ротацией реальных ключей.
