Создание AI-агента

Один основной sales-агент на продукт. Агент создаётся для продукта без агента и начинает работать только после публикации первой версии.

AI-провайдер OpenRouter подключён · модель по умолчанию gpt-4o-mini
1

Продукт

Доступны только продукты без sales-агента. У продукта может быть не более одного агента.

У продуктов FirePage и Foxray агент уже есть — для них доступен переход в существующую карточку, а не создание второго.
2

Базовая модель

Стартовая конфигурация создаётся из разрешённой модели. Позже модель и параметры меняются в карточке агента.

Список моделей задаётся в интеграции OpenRouter.
3

Стартовые инструкции

Создадим черновые prompt-документы. Доработать их можно в карточке агента до публикации.

Квалификация Поведение в продаже Ограничения — будут созданы как черновики
4

Обязательные знания

Выберите материалы из базы знаний продукта. Они войдут в retrieval index первой версии.
