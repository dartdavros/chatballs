# Дополнение к существующему экрану сотрудников

Владелец утвердил фильтры роли и статуса в этой переписке: «Да, норм. Делай».
Источник: существующий экран сотрудников и его компоненты.

- `screen-closed.svg` — существующий список с выпадающими ролью и статусом.
- `screen-role.svg` — открытый выбор роли.
- `screen-status.svg` — открытый выбор статуса: активен, приглашён, заблокирован,
  уволен. «Все» по умолчанию не включает уволенных.
- `screen-dismissal.svg` — подтверждение увольнения, отдельно утверждённое
  владельцем в этой переписке («Утверждаю»). Последующее указание владельца:
  «Уволить сотрудника» размещается в опасной зоне карточки сотрудника.

PNG рядом служат изображениями для просмотра. `index.html` открывает макет
фильтров. Это дизайн, а не запущенное приложение.
