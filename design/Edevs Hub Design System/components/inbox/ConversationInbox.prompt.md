The dense realtime inbox list used in Продажи · Диалоги — one row per conversation, showing who's currently in it (AI vs operator), which channel, and whether it's waiting for a human.

```jsx
<ConversationInbox items={[
  { name: 'Мария Соколова', preview: 'Здравствуйте! Чем...', channel: 'max', lastActor: 'ai', time: '5 мин', waiting: true },
]} />
```
