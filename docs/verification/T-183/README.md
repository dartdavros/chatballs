## Изменения

В ContactActions полный список заменён на существующий ManualActionMenu.
ContactEntityLinks, контекст, каталог и openAction не изменены.
Карточка агента содержит только прежнее описание и вход настройки.
Редактор находится в AgentActionsDialog; строка — AgentActionRow;
группировка/поиск — чистая модель catalogGroups.

Категории определяются пространством имён native ID; исполняемые сценарии
отдельны от управления сценариями Chatballs. Внешние операции группируются
по ID подключения, название берётся из существующего subtitle.
Нет второго списка операций, анализа переведённых названий или изменений backend.
Неизвестное пространство имён сохраняется в общей категории.

Фильтруется только представление. useAgentActions/saveActions получают полный
набор изменённых строк с исходными ревизиями. Ref блокирует повторную отправку
до завершения запроса. Ошибка не закрывает редактор. Отмена с правками использует
штатный диалог: остаться, не сохранять или явно сохранить.
Кнопка сохранения из общего заголовка перенесена в редактор.
