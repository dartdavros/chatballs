# Выпуск 1.24.0: публикации, права и увольнение

Дата проверки: 23.11.2026. Выпуск собран отдельно от незавершённых документов
других задач, поверх опубликованного v1.23.1. Рабочие аккаунты и данные для
проверки не менялись. Подтверждение увольнения в браузере отменено.

## Проверки

- Браузер штатного Chatballs: совместная фильтрация роли и статуса, карточка
  владельца только для просмотра, отсутствие его административных действий,
  кнопка увольнения в опасной зоне обычного сотрудника, подтверждение и отмена.
- Полный прогон internal-ui: 98 файлов, 533 теста прошли. Для Node задана
  русская локаль, предусмотренные branding-тестом design assets примонтированы
  read-only; два worker и timeout 30 секунд учитывают Docker Desktop/Windows.
- Дополнительная проверка начала работы: 6 тестов прошли; шаг платформы
  использует текущее серверное право, а не только isInstanceAdmin.
- Целевой серверный прогон: 152 прошли, один старый тест ожидал запрета
  владельцу проверять/устанавливать обновления. Ожидание приведено к новым
  требованиям; отдельный повтор вместе с расписанием сообщений: 17 тестов прошли.
- Полный серверный прогон остановлен на пяти ошибках: 248 прошли. Все пять
  ошибок воспроизведены на чистом v1.23.1 в отдельной тестовой БД: три случая
  AgentListPaginationTests, AssistanceStorageTests.test_state_and_safe_error_constraints,
  DiagnosticCaptureTests.test_diagnostic_storage_error_does_not_lose_the_customer_reply.
  Полностью зелёный серверный набор не заявляется.
- Production backend и frontend собраны штатными Dockerfile. Последующий
  импорт-only lint fix и __str__ модели проверяются финальной сборкой backend.
- Ruff проверяется из /app с корневым pyproject.toml — те же настройки, что CI.

Логи команд находятся в локальном tmp/release-20261123. Секреты, дампы БД и
полные журналы рабочего приложения в коммит не включены. Выпуск Backoffice
должен предшествовать обновлению Chatballs: старый суточный API совместим,
отдельный поток требует ASGI. План серверного изменения согласуется отдельно
по AGENTS.md; этот отчёт сам не является разрешением на production.
