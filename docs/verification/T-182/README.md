## Браузер: фактическая панель

Использован task-local Playwright. Проверены штатные действия: открытие
разрешения микрофона → крестик; запись → крестик; остановка → ожидание →
редактирование → крестик; отказ разрешения; повторное открытие. Escape в поле
скрывает панель, Shift+Enter добавляет перенос без отправки.
Набранный черновик оставался в поле. Панель после закрытия отсутствовала,
постоянного «Диктовка отменена» нет. Черновик из 4001 символа сохранён целиком,
крестик скрывает и предупреждение о длине.

В настоящей попытке ожидания отображалось «Распознаём речь… Можно печатать».
После крестика наблюдаемый AbortSignal.aborted=true, все полученные дорожки
имели readyState=ended. Поздние ответы защищены прежним DraftAttempt;
эта защита проверена адресным тестом. Перехват в браузере только наблюдал
настоящие fetch/MediaStream, ответы API не заменялись. В журнале браузера
был один отменённый POST dictation, остальные POST — observations;
запросов отправки сообщения не было.
Read-only проверка backend-admin для созданной браузером WebSession 19
подтвердила **0 Conversation и 0 Message** её контакта.

После уточнения владельца проверки качества STT, минутных лимитов, TTS и
совместимости провайдеров не повторялись. Для визуальной матрицы результат,
отмена, permission/recognizing и ошибки задавались непосредственно штатному
React-состоянию notice в работающем приложении. Это проверка отображения и
реального обработчика крестика, **не** сквозной успешный STT или имитация
ответа backend. 48 сочетаний: ru/en × 320/390/1280 × восемь notice-состояний.
Обрезания, наложения текста/действий и горизонтального переполнения нет;
в каждом случае крестик убирал панель и сохранял черновик.
