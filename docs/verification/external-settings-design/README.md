# Сверка настроек внешнего исполнения с утверждённым макетом

Дата: 2026-11-16. Исправление выполнено по прямому указанию владельца в проектном чате.

## Источник дизайна и изменения

Начальная настройка сверена с S01/S02 из `design/baseline/external-agent/settings-off` и `settings-unconfigured`. Сохранённая конфигурация и её состояния сверены с утверждённым пакетом `REST-66e46e103944410c`: S20–S39, S72/S73 в `design/baseline/external-agent/remainder`. SHA-256 утверждённого `generated/runtime.js`: `926c4358a4a03d354bafa5d53548428b301a331cc7b117485bd46992a7235454`. Макеты не изменялись.

- В сохранённом подключении восстановлены два соседних поля ключей с подписями и действиями. Кнопка проверки и область результата находятся после полей, как в макете. Убраны секции начальной настройки, ошибочно перенесённые в сохранённое подключение.
- В начальной настройке восстановлена компактная обёртка статуса «Ключ ещё не создан» и отступ перед ошибкой сохранения.
- Восстановлены заголовки, пояснения и статусы включённой возможности, сохранённой выключенной конфигурации и повторной проверки полномочий. Пояснения используют реальные имена агентов и подключения.
- Исправлены размещение предупреждения в карточке связей и структура диалога удаления связи.
- Состояния загрузки, ошибки загрузки, проверки подключения, сохранения и повторного включения разделены. Восстановлены предусмотренные макетом область загрузки, кнопка повтора и подписи.
- Устаревшие разрешения на поля и шаблоны не сопровождаются противоречащими им сообщениями о пустом наборе разрешений.
- Для этой страницы сохранена предусмотренная утверждённым макетом минимальная ширина оболочки 1024 px. Это устраняет отличие, вызванное порядком подключения общих стилей на ширине 390 px.

Отдельно согласованное владельцем в T-193 поле выбора режима обработки сохранено. В исходном S20 этого поля нет; это ранее утверждённое исключение, а не новое изменение дизайна.

## Проверка

Использован существующий штатный Compose-контур проекта: UI `http://localhost:5174`, backend `http://localhost:8010`. Готовность backend подтвердила доступность PostgreSQL и Redis. Вход выполнен существующим демо-администратором.

В используемой базе уже было включённое подключение «Тест» с сохранёнными скрытыми ключами, результатом «Сервис недоступен» и без связей с агентами. Проверялись именно эти реальные данные. Ключи не раскрывались. Внешний адрес не вызывался. Подключения, привязки, права и учётные данные не создавались и не изменялись; seed, заглушки и подмена API не использовались.

В Chrome/Playwright проверены:

- светлая и тёмная темы при 1440 px, тёмная тема при 1024 и 390 px;
- размеры и координаты карточки возможности, карточки подключения, полей, действий и результата относительно контента — совпали с S29 на каждой проверенной ширине;
- диалоги замены и отзыва входящего ключа, выключения возможности и справка раздела; все операции отменены, снимки диалогов сделаны после завершения анимации;
- изменение названия только в локальном черновике: появилась подпись несохранённых изменений, кнопка сохранения стала доступна; перезагрузка восстановила сохранённое название;
- после чистой загрузки ошибок JavaScript нет; изменяющих запросов к API настроек во время проверки нет.

Тёмная тема применялась штатной функцией оформления к проверочной странице без записи предпочтений профиля. Проверочные headless-браузеры закрыты.

Сборка `tsc -p tsconfig.json && vite build` для `@chatballs/internal-ui` завершилась успешно. Vite сообщил о крупных чанках. Полный набор тестов не запускался.

Проверено разделение ответственности: затронутые компоненты небольшие, поля сохранённых ключей вынесены в отдельный `SavedAccessFields.tsx`; самый длинный затронутый файл — целевой тест, 92 строки.

## Границы подтверждения

В текущей базе нет связей этого подключения с агентами. Поэтому сценарии обработки, разрешений на поля и шаблоны, начального отсутствия ключа, сохранённого выключенного состояния и ошибок включения проверены компонентными тестами и сопоставлением исходников с утверждённым макетом, но не воспроизводились целиком в штатном браузере. Все состояния страницы не объявляются полностью проверенными в браузере. Настройки ради получения таких состояний не менялись.
