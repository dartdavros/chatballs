# Навыки: отдельный раздел и единые элементы интерфейса

## Исходник и изменения

Патч подготовлен относительно предоставленного архива `chatballs(2).zip` по запросу владельца от 11.11.2026.

- «Навыки» вынесены в самостоятельный пункт левого меню после «Агентов», в группе AI и автоматизации. Используется прежняя иконка пазла `SkillGlyph`.
- Убраны вкладки переключения между списком агентов и навыками. Библиотека получила собственный заголовок «Навыки».
- Адрес `/organizations/:org/agents/skills`, ссылки на конкретный навык и заголовок вкладки «Навыки · Chatballs» сохранены.
- Видимость пункта сохраняет прежнюю границу OWNER/ADMIN. Серверные разрешения не менялись.
- Фильтр агента переведён на общий `FilterDropdown`/`SelectMenu`, используемый в списках сотрудников и шаблонов. Сохраняются значение ID карточки агента, вариант «Все», поиск и серверная пагинация.
- Общая подпись фильтра получила ограничение доступной ширины и многоточие для длинных имён; полный текст доступен при наведении. Счётчик множественного выбора сохраняет прежний вид. Стили фильтра выделены из большого `ui-controls.css` в небольшой `filter-dropdown.css`.
- Нижняя область сохранения оформлена по существующему `InstructionsCard`: разделитель, сообщение об изменениях и штатные кнопки. Убраны плавающая плашка, отрицательные отступы и локальные подмены размеров основных кнопок.
- Первый пункт выбора основы навыка переименован из «С нуля» в «Новый навык»; английская подпись — `New skill`. Значение пустой основы и создание навыка не менялись.
- Baseline навыков и sidebar, а также соглашение UI обновлены по этому запросу.

## Сохранённое поведение

Верхняя «Отмена» запрашивает выход из редактора через существующую защиту несохранённых изменений. Нижняя «Отменить изменения» подтверждает сброс к сохранённой версии, оставаясь в редакторе.

Сохранены общий черновик навыка и шаблонов, атомарное сохранение, состояния `busy`/`conflict`/`dirty`, сообщение «Сохранить для N агентов», обработка ошибок и временно невалидного JSON примеров. Клик активного пункта «Навыки» возвращает библиотеку только после разрешённого перехода; Back/Forward обновляет выбранный навык. Внутренний `replaceState` после первого сохранения не пересоздаёт редактор.

## Применение

Распаковать архив патча в корень существующего проекта, где лежит `package.json`, с заменой файлов. Архив содержит только добавленные и изменённые файлы; дополнительной папки `chatballs/` нет. Удалять файлы не требуется.

Из корня проекта:

```powershell
npm --workspace @chatballs/internal-ui run build
```

Если зависимости ещё не установлены, перед сборкой выполнить `npm ci`. Манифесты и lock-файл этим патчем не изменены. Для этого обновления новые миграции БД не требуются. Обновить frontend привычным способом и перезагрузить страницу.
