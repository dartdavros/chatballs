# Действия агента

В карточке агента блок «Действия и сценарии» показывает операции подключённых
сервисов и включённые сценарии, в запуске которых выбран этот агент.
Владелец или администратор выбирает режим каждого действия и сохраняет изменения:

- «Запрещено» — агент не получает действие.
- «Самостоятельно» — агент может выполнить действие без сотрудника, включая
  явно разрешённые создание, изменение и удаление.
- «С подтверждением» — сотрудник сначала проверяет точные значения и контекст.

Редактор сценария и карточка агента меняют одно разрешение. Старые инструменты
и навыки не включают новые действия автоматически. Выключенные подключения
и сценарии недоступны. Восстановление доступа не возвращает отозванное разрешение.

## Подтверждение в диалоге

Запрос виден сотрудникам в ленте. Проверьте действие, подключение и все
параметры, включая ответственного во внешнем сервисе. Решение принимает
администратор либо текущий уполномоченный ответственный за диалог. Видимость
карточки участнику сама по себе не даёт права подтверждать.

Решение действует 30 минут для указанных значений. «Изменить» открывает поля
текущего запроса; определение сценария остаётся прежним. Пока сотрудник
редактирует, другой не может подтвердить запрос. «Подтвердить с изменениями»
подтверждает новые значения; прежнее подтверждение для них не подходит.
«Отклонить» останавливает новые эффекты, но не отменяет уже полученный результат.
Текст клиента, агента или внешнего события не считается согласием сотрудника.

## Проверка агента

По умолчанию выбрана «Проверка»: параметры проверяются без запуска и изменений
сервиса. Карточка помечена «Не выполнялось». Для реального запуска явно выберите
«Настоящее выполнение». Предупреждение напоминает, что изменения во внешнем
сервисе настоящие. Права и режим действия сохраняются; подтверждаемые действия
не обходят решение сотрудника.

## Результат

Агент получает номер и фактическое состояние запуска. Ожидание или выполнение
не означает успех. Карточка обновляется по мере работы; подробности доступны
из диалога, на телефоне — внутри чата. Модель может запросить актуальный статус
в следующем ходе. Завершение само по себе не запускает отдельную бесконечную
переписку и не меняет провайдера.

Перед новым эффектом и ответом проверяются актуальные права и управление
диалогом. После перехвата, выключения ИИ или отзыва разрешения старый запуск
не получает права на поздний автономный ответ, даже если управление затем вернули.
Уже отправленный запрос может завершиться: настоящий исход остаётся в журнале.

Хранение и восстановление описаны в [справке сценариев](scenarios.ru.md).
