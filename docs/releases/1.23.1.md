# Chatballs 1.23.1

- Установки с включёнными внешними проверками передают настроенный публичный адрес в Backoffice вместе с версией и идентификатором установки. Адрес можно использовать для поиска в реестре Backoffice.
- После обновления poller отправляет check-in при первом запуске с новой версией, сохраняя идентификатор установки и соблюдая срок ожидания после ограничения частоты запросов.

Штатное обновление с 1.23.0 применяет миграцию расписания check-in.
