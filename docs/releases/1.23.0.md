# Chatballs 1.23.0

Подключение установок Chatballs к Backoffice и сервисные сообщения в рабочей области.

## Backoffice

- Установка проверяет сервисные сообщения через Backoffice. Запрос передаёт идентификатор установки и версию Chatballs.
- В разделе «Настройки → Платформа → Обновления» администратор установки может отключить обращения к Backoffice и проверки обновлений GitHub. По умолчанию они включены.
- Сервисные сообщения отображаются над рабочей областью администратора установки в порядке, заданном Backoffice. Если у сообщения есть ссылка, её можно открыть из баннера.
- GitHub Releases остаётся источником новых версий Chatballs. Сбой Backoffice не мешает проверке обновлений.

## Обновление с 1.22.0

Штатное обновление применяет миграции настроек внешних проверок и хранения сервисных сообщений. В релизном Compose нет новых обязательных сервисов.
