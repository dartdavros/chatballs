# Chatballs 1.24.0

- Сервисные сообщения доставляются по открытому соединению с Backoffice,
  независимо от суточной отметки связи. Публикация с началом «сейчас» появляется
  после получения. Будущие сообщения появляются в начале окна и скрываются
  при его окончании без перезагрузки страницы. Потеря связи не продлевает показ.
- Администратор получает те же права в организации, что и владелец, включая
  управление администраторами. Владельца нельзя изменять, блокировать,
  увольнять или удалять. Только сам владелец может передать владение.
- Доступ к «Платформе» получают действующие владельцы и администраторы.
  Изменение TURN и хранилища сохраняет отдельную проверку администратора установки.
- В опасной зоне карточки сотрудника добавлено увольнение с подтверждением.
  Доступ к организации прекращается, открытые обращения возвращаются в очередь.
  История, учётная запись и доступ к другим организациям сохраняются.
- Роль выбирается выпадающим списком. Добавлен фильтр статуса: активен,
  приглашён, заблокирован, уволен. Общий список не включает уволенных.

Штатное обновление применяет миграции участия сотрудника и расписания сообщений.
Новых обязательных сервисов и изменений размещения данных нет. Для новой
доставки сообщений сначала обновляется Backoffice с поддержкой потока публикаций;
старый суточный API остаётся совместимым с предыдущими версиями Chatballs.
