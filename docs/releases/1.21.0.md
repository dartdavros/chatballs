# Chatballs 1.21.0

Обновление навигации, библиотеки навыков и выбора действий в диалогах.

## Навигация и поиск

- Настройка AI-провайдеров, сценарии и навыки доступны из левого меню.
- Виджеты, мессенджеры, MCP и HTTP, а также интеграции с внешними службами разделены на самостоятельные пункты.
- Пункты меню объединены в группы по назначению; обновлены соответствующие иконки.
- Заголовок вкладки браузера отражает открытый раздел, например «Чаты · Chatballs».
- Поля поиска получили подсказку `/`. Клавиша переводит фокус в подходящее поле поиска с учётом открытого окна и не мешает вводу текста.

## Действия в диалогах

- Вместо плоского списка открывается модальное окно выбора действия с поиском и вложенными группами.
- Действия сгруппированы по подключениям и категориям. Например: Битрикс24 → CRM → создание лида.
- Поиск учитывает названия действий, подключений и категорий; найденные ветки раскрываются.
- Собственным сценариям можно задать путь категории. Сценарии без категории остаются доступны в отдельной группе.
- Список учитывает активность сценариев, права сотрудника, доступность подключений и контекст диалога.
- Сервер повторно проверяет доступ при подготовке, запуске и повторе действия.
- Выбор действия открывает форму подготовки. Выполнение требует отдельного подтверждения сотрудника.

## Навыки

- Библиотека навыков получила отдельный пункт левого меню и собственный заголовок.
- Фильтр по агенту приведён к общему оформлению списков платформы.
- Область сохранения и отмены изменений оформлена в соответствии с другими редакторами.
- Сохранены предупреждения о несохранённых изменениях и существующее поведение сохранения.
- Пункт создания навыка «С нуля» переименован в «Новый навык».

## Отображение сообщений

- Улучшено отображение ссылок, переносов строк, списков, цитат и форматированного текста в диалогах.
- Учтены особенности форматирования сообщений Telegram.
- HTML и небезопасные адреса в сообщениях не исполняются; изображения из Markdown не загружаются автоматически.

## Обновление с 1.20.3

Используйте штатный механизм обновления или опубликованный compose.yaml с сохранением существующих настроек и override-файлов установки.

В выпуск включена миграция integrations.0034_scenario_category_path. Она добавляет поле категории сценария с пустым списком по умолчанию. При штатном обновлении миграцию выполняет сервис init.

Перед обновлением рабочей установки подготовьте резервную копию базы данных и проверьте возможность её восстановления. Возврат предыдущих Docker-образов сам по себе не отменяет изменения схемы базы.
