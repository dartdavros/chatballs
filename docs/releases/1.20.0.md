# Chatballs 1.20.0

Сервисные сценарии, речевые функции веб-виджета и первый ответ агента по событию сайта.

## Возможности

- Подключения сервисов, готовые и пользовательские сценарии в общем редакторе:
  шаги, условия, ожидания, вложенные сценарии и привязка данных.
- Ручной запуск, запуск агентом, по событиям, расписанию и API; журнал,
  восстановление после сбоев и управление выполнением. Внутренние действия
  используют те же проверки доступа и прикладные операции, что интерфейс.
- Каталог действий общения, обслуживания, настройки организации, контента
  и установки. Административные и личные действия сохраняют отдельные права
  и не становятся доступными агенту через обычный каталог организации.
- Диктовка в веб-виджете и отдельный провайдер распознавания Yandex SpeechKit.
  Распознанный текст можно проверить перед отправкой. Прослушивание ответа
  агента через SpeechKit включается отдельно и запускается пользователем.
- Явное событие сайта через `Chatballs.emitEvent()` может показать приглашение
  и запустить первый ответ агента после согласия клиента. Повтор события
  не создаёт повторный первый ответ.

## Исправления

- Защищённые WebSocket-сессии работают за прокси, передающим
  `X-Forwarded-Proto: wss`. Проверка источника соединения и защита обычного
  HTTP сохраняются.

## Обновление

Обновление выполняется штатным способом через интерфейс или `compose.yaml`
релиза с существующими override-файлами. Новые обязательные сервисы не нужны.

Относительно 1.19.1 добавлены миграции: `ai.0030–0031`,
`conversations.0048`, `integrations.0015–0033` (включая объединение ветвей),
`tenancy.0068–0080`, `webchat.0009–0012`. Их выполняет штатный сервис `init`.
Перед обновлением сохраните резервную копию БД, файлов и томов секретов.
Откат только образов не отменяет изменения схемы и данных.

## Проверки и ограничения

Отчёты реализации: [T-176](../verification/T-176/README.md),
[диктовка](../verification/T-178/README.md),
[прослушивание](../verification/T-179/README.md),
[события сайта](../verification/T-181/README.md).

Полный путь с реальным внешним сервисом, внешними изменениями, OAuth,
callback и восстановлением на границе внешнего эффекта остаётся непроверенным:
владелец явно отложил эти проверки. Наличие общего механизма не расширяет
возможности конкретного адаптера; полная готовность всех интеграционных
сценариев не заявляется.

Перед выпуском собраны production-образы backend и frontend. Прошли Ruff,
Django check, проверка отсутствия незаписанных миграций, адресные backend-тесты
каталога действий, исполнения, согласия, речи и событий сайта, 16 frontend-тестов
речи и очереди событий, 15 тестов релизного Compose. Проверки аудиоформатов
выполнены с настоящим FFmpeg из production-образа. Одна Compose-проверка
пропущена: Docker CLI отсутствует внутри тестового backend-контейнера;
опубликованный Compose дополнительно проверяется на хосте.

Полный набор тестов проекта не запускался. Результаты CI и публикации образов
доступны в GitHub Actions.
