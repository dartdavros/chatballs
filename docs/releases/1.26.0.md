# Chatballs 1.26.0

- Агент может приветствовать клиента при старте веб-чата с ИИ и без него. В приветствии доступны переменные из полей подключённых виджетов.
- MCP и HTTP поддерживают операции записи. Разрешение и требование подтверждения задаются для каждой операции.
- Статьи портала можно сохранять и публиковать в системном разделе «Без раздела». Поля редактора используют оформление дизайн-системы.
- Веб-виджет поддерживает светлую и тёмную темы, а пользовательский CSS применяется и к кнопке открытия чата. Текст согласия отображается без номера редакции.
- При пустом списке сценариев кабинет показывает стандартное пустое состояние с кнопкой «Создать сценарий».

Штатное обновление применяет миграции приветствия агента, веб-сессий и системного раздела портала.
